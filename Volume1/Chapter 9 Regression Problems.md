## 第9章　回帰問題

**この章でわかること**

- 回帰が連続的な数値を予測する問題であること
- 線形回帰、誤差、MSE、MAE、RMSE の基本
- 外れ値や過小適合、過学習が回帰に与える影響
- Transformer も出力層を変えれば回帰問題に使えること

### 9.1　回帰とは何か

回帰とは、入力から連続的な数値を予測する問題です。分類では出力はカテゴリでしたが、回帰では出力は数値です。

```text
家の情報 → 価格
気象情報 → 明日の気温
過去の売上・天気・広告費 → 明日の売上金額
```

分類と回帰の違いは、出力がカテゴリか数値かです。ただし、同じ対象でも何を出力したいかによって変わります。「明日の気温が30度を超えるか」を予測するなら分類、「明日の気温そのもの（31.4度）」を予測するなら回帰です。

分類では「当たったか外れたか」が中心でしたが、回帰では「どれくらいズレたか」が中心になります。

```text
正解：100 / 予測：98  → かなり近い
正解：100 / 予測：40  → 大きく外れている
```

この「ズレ」をどう測るかが、回帰問題では重要になります。

```mermaid
flowchart LR
    A["入力特徴量"] --> B["回帰モデル"]
    B --> C["予測値"]
    D["正解値"] --> E["誤差を計算"]
    C --> E
    E --> F["モデル改善の手がかり"]
```

### 9.2　連続値を予測する

回帰問題では、連続値（ある範囲の中で細かく変化する数値）を予測します。気温（22.0度、22.15度…）、価格、売上、体重、距離、時間などが対象です。

回帰モデルは、入力を受け取り、数値を返します。

```text
予測価格 = モデル(広さ, 築年数, 駅距離, 地域)  → 例：7,850万円
```

分類なら「正解したかどうか」を見ますが、回帰では予測が完全に一致することはあまり期待しません。価格や気温では少しのズレは普通に起こるので、「どれくらい近いか」を評価します。正解8,000万円に対し予測7,850万円なら誤差150万円、というように、回帰問題では誤差の大きさが重要です。

### 9.3　線形回帰

回帰の基本的なモデルに、線形回帰があります。入力特徴量の重み付き和で数値を予測するモデルです。

家の広さだけから価格を予測する場合、`価格 = 広さ × 重み + バイアス`、数式風に `y = wx + b`（x が入力、y が予測値、w が重み、b がバイアス）です。たとえば `価格 = 広さ × 100万円 + 500万円` なら、広さ70平米で `70 × 100万 + 500万 = 7,500万円` です。

入力特徴量が複数ある場合は、それぞれに重みが付きます。

```text
価格 = 広さ × w1 + 築年数 × w2 + 駅距離 × w3 + バイアス
```

広さが価格を上げる要因なら広さの重みは正、築年数が古いほど価格が下がるなら築年数の重みは負、というように学習されます。線形回帰は単純ですが、「入力・重み・バイアス・予測値・正解との差・差を小さくするように重みを調整」という機械学習の基本がすべて詰まっており、この流れはニューラルネットワークや Transformer でも基本的に同じです。違うのは、構造が複雑になりパラメータ数が非常に多くなることだけです。

#### PyTorchで確認してみる

次のコードは、小さな線形回帰モデルを学習します（`x` は広さを100で割った値、`y` は価格を100で割った値）。

```python
import torch
from torch import nn

torch.manual_seed(0)

x = torch.tensor([[0.4], [0.6], [0.8], [1.0]])
y = torch.tensor([[0.45], [0.65], [0.85], [1.05]])

model = nn.Linear(1, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
loss_fn = nn.MSELoss()

for step in range(200):
    y_hat = model(x)
    loss = loss_fn(y_hat, y)

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()

with torch.no_grad():
    test_x = torch.tensor([[0.7]])
    prediction = model(test_x)

print("weight:", model.weight.item())
print("bias:", model.bias.item())
print("prediction:", prediction.item())
```

学習が進むと、モデルは `y` が `x` にほぼ比例している関係を捉えます。ここでも学習しているのは `weight` と `bias` です。

### 9.4　誤差の測り方

回帰問題では、予測値と正解値のズレ（誤差）を測ります。もっとも単純には `誤差 = 予測値 - 正解値` ですが、予測が低いとマイナス、高いとプラスになります。

```text
予測 7,500・正解 8,000 → 誤差 -500
予測 8,500・正解 8,000 → 誤差 +500
```

モデルの悪さを測るときは、誤差の向きより大きさが重要です（どちらも500ズレている）。そこで、誤差の絶対値や二乗を使います。

```text
絶対誤差 = |予測値 - 正解値|
二乗誤差 = (予測値 - 正解値)^2
```

二乗誤差では、大きな誤差がより強く罰せられます（誤差が10倍になると二乗誤差は100倍）。そのため、二乗誤差を使うと大きく外すことを特に避けるモデルになります。どの測り方を使うかは、何を悪い予測とみなすかに関係します。

### 9.5　誤差を測る指標（MSE・MAE・RMSE）

回帰でよく使われる損失関数に、平均二乗誤差（Mean Squared Error, MSE）があります。各データの二乗誤差を計算し、その平均を取ります。

```text
データ1：予測 100、正解 110、二乗誤差 100
データ2：予測 200、正解 180、二乗誤差 400
データ3：予測 300、正解 330、二乗誤差 900
MSE = (100 + 400 + 900) / 3 = 466.7
```

MSE が小さいほど、予測は全体として正解に近いと考えます。MSE の特徴は、大きな誤差を強く罰することです。価格予測で「少し外すのは許容できても大きく外すのは困る」場合などに便利です。一方、MSE には外れ値に弱いという性質があります。極端に高額な豪邸が1件混ざっていると、その大きな誤差が二乗で大きくなり、モデル全体がそのデータに引っ張られることがあります。

**平均絶対誤差**

平均絶対誤差（Mean Absolute Error, MAE）は、各データの絶対誤差を計算し、その平均を取ります。

```text
データ1：絶対誤差 10 / データ2：絶対誤差 20 / データ3：絶対誤差 30
MAE = (10 + 20 + 30) / 3 = 20
```

MAE は「平均してどれくらいズレているか」を直感的に理解しやすい指標です（MAEが300万円なら平均して300万円くらいズレている）。MSE と MAE の違いは、大きな誤差の扱いです。MSE は誤差を二乗するため大きな誤差を強く罰し、MAE は絶対値を使うため罰は比較的穏やかです。外れ値が多い場合は MAE の方が安定して評価できることがありますが、学習のしやすさという点では MSE の方が扱いやすい場合もあります。

**RMSE**

RMSE（Root Mean Squared Error）は、MSE の平方根を取ったものです。

```text
RMSE = sqrt(MSE)
```

なぜ平方根を取るのでしょうか。MSE は誤差を二乗しているため、単位も二乗されます（価格を万円で測ると MSE の単位は「万円の二乗」のようになり、直感的に解釈しにくい）。平方根を取ることで、元の単位に戻します。価格予測で RMSE が500万円なら、「大きな誤差を強めに反映した上で、典型的なズレは500万円程度」と解釈できます。RMSE は MSE と同じく大きな誤差に敏感（外れ値があると大きくなりやすい）ですが、元の単位で解釈できる利点があります。

```text
MAE ：平均的にどれくらいズレるかを直感的に見やすい
MSE ：大きな誤差を強く罰するが、単位が二乗になる
RMSE：大きな誤差を強く反映しつつ、元の単位で解釈できる
```

回帰問題では、これらの指標を目的に応じて使い分けます。

### 9.6　外れ値の影響

回帰問題では、外れ値（他のデータから大きく外れた値）の影響に注意する必要があります。

ほとんどの物件が3,000万円〜1億円なのに、50億円の特殊な豪邸が1件入っていたら、それは外れ値かもしれません。多くの一般的な物件の価格を予測したい場合、その1件にモデルが強く引っ張られると困ります。特に MSE や RMSE は大きな誤差に敏感なので、外れ値に大きく外すと二乗によって損失が非常に大きくなり、モデルが外れ値に合わせようとしすぎるかもしれません。一方、MAE は誤差を二乗しないため、外れ値の影響は比較的穏やかです。

外れ値への対応には、データの誤りとして除外する、外れ値に強い損失関数を使う、対数変換などでスケールを調整する、などがあります（価格は範囲が広いので、価格そのものではなく対数を予測することもあります）。ただし、単純に削除すればよいとは限りません。外れ値が本番でも出てくる重要なケースなら、むしろ扱えるようにする必要があります。大事なのは、その外れ値がデータ入力ミスなのか、まれだが重要なケースなのか、本番でも予測したい対象なのかを考えることです。

### 9.7　過小適合と過学習

回帰問題でも、過小適合と過学習が起こります。

過小適合は、モデルが単純すぎて訓練データの傾向を十分に捉えられない状態です。価格が地域・駅距離・築年数など複数の要因で決まるのに、広さだけの単純な直線モデルで予測しようとすると、訓練データに対しても誤差が大きくなります（訓練誤差も検証誤差も大きい）。

一方、過学習は、モデルが訓練データに合わせすぎて未知のデータに弱くなる状態です。非常に複雑なモデルが訓練データのノイズや特殊事情まで覚えてしまうと、新しい物件では大きく外すかもしれません（訓練誤差は小さいが検証誤差は大きい）。

回帰でも、分類と同じように訓練データと検証データを分けて評価する必要があります。モデルの目的は、訓練データにぴったり合うことではなく、未知のデータに対して誤差の小さい予測をすることです。

### 9.8　回帰モデルの評価

回帰モデルを評価するときは、目的に合った評価指標を選ぶ必要があります。代表的なのは MAE（平均的なズレ）、MSE（大きな誤差を強く罰する）、RMSE（大きな誤差を反映しつつ元の単位で解釈）です。大きな外れを特に避けたいなら MSE や RMSE、外れ値に引っ張られすぎたくないなら MAE が向きます。

また、評価指標は数値だけ見ても意味がわかりにくいことがあります。RMSE が100でも、気温予測なら明らかに悪いですが、年商を億円単位で予測する問題で RMSE が100万円なら非常に良いかもしれません。評価指標は対象のスケールと一緒に解釈する必要があります。

さらに、平均的な誤差だけでなく、誤差の分布を見ることも重要です。

```text
ほとんどのケースで少しズレるのか / 一部のケースで大きく外すのか
高い値だけ過小評価するのか / 特定の条件で外しやすいのか
```

回帰モデルを実用で使うには、単一の指標だけでなく、誤差の傾向を見ることが大切です。

### 9.9　分類と回帰の違い

ここで、分類と回帰の違いを整理します。

```text
分類：入力 → カテゴリを予測（犬 / 猫）。正解したかどうかを見る
回帰：入力 → 数値を予測（価格）。どれくらいズレたかを見る
分類の評価：精度、適合率、再現率、F値、混同行列
回帰の評価：MAE、MSE、RMSE、誤差分布
```

また、分類では softmax やシグモイドで確率を出すことが多く、回帰では出力層からそのまま数値を出すことが多いです。

ただし、分類と回帰は完全に別世界ではありません。数値を区間に分ければ分類問題にできます（家の価格を「3,000万円未満」「3,000万〜5,000万」…のカテゴリに分けるなど）。逆に、分類の確率（病気である確率0.82）を数値として扱うこともあります。重要なのは、目的に応じて問題の形を設計することです。

### 9.10　回帰とニューラルネットワーク

ニューラルネットワークでも回帰問題を扱えます。基本的な考え方は同じで、入力を受け取り、何層もの計算で変換し、最後に数値を出力します。

```text
[広さ, 築年数, 駅距離, 地域情報, 部屋数] → ニューラルネットワーク → 予測価格 8,200万円
```

分類問題では最後に softmax を使ってカテゴリごとの確率を出すことが多いですが、回帰問題では最後にそのまま数値を出すことが多いです。

```text
分類：出力層 → softmax → 確率分布
回帰：出力層 → 数値
```

予測したい数値の範囲が決まっている場合は、出力に制約をかけることもあります（0〜1ならシグモイドを使うなど）が、一般的な回帰では出力は自由な実数として扱うことが多いです。

学習時には、予測値と正解値の誤差から MSE や MAE などの損失を計算し、逆伝播でパラメータを更新します。つまり、ニューラルネットワークの回帰も「予測する → 正解と比べる → 損失を計算する → 勾配を求める → 重みを更新する」という基本は同じです。

### 9.11　回帰問題で注意すべきこと

回帰問題では、いくつか注意すべき点があります。

まず、**出力値のスケール**です。価格を円単位（80,000,000円）で扱うと値が非常に大きくなり、学習が不安定になることがあります。そのため、入力特徴量や出力値を適切にスケーリング（百万円単位にして80にするなど）することがあります。

次に、**外れ値の扱い**です。一部の極端な値がモデルや評価指標に大きく影響することがあり、特に MSE や RMSE では注意が必要です。

また、**誤差の意味**を考えることも重要です。100万円の誤差は、3,000万円の物件では大きいかもしれませんが、10億円の物件では小さいかもしれません。絶対誤差だけでなく、相対誤差（正解値に対して何％ズレたか）を見たい場合もあります。

さらに、予測したい値が**負になってはいけない**場合（価格、人数、売上、時間など）もあります。普通の回帰モデルはマイナスを出すことがあるので、出力の変換や後処理、モデル設計で制約を考える必要があります。

最後に、**平均的な誤差だけで満足しない**ことが重要です。全体の MAE が低くても、高価格帯だけ過小評価する、特定地域だけ外しやすい、といった偏りがあるかもしれません。回帰モデルでは、誤差の分布や偏りを見ることが実用上とても重要です。

### 9.12　本章のまとめ

**Transformer への接続**

大規模言語モデルの基本的な事前学習は分類問題として扱うことが多いですが、Transformer 自体は回帰にも使えます。テキストや時系列データを入力して、スコア、価格、需要量、連続的な評価値などを予測するように出力層を設計すれば、Transformer を回帰モデルとして使えます。

この章では、回帰問題について学びました。回帰とは、入力から連続的な数値を予測する問題です（家の情報→価格、気象情報→気温、など）。分類がカテゴリを予測するのに対し、回帰は数値を予測します。

回帰では、予測値と正解値のズレ（誤差）を測ります。代表的な評価指標は、MAE（平均的なズレ）、MSE（大きな誤差を強く罰する）、RMSE（元の単位で解釈しやすく、大きな誤差にも敏感）です。回帰でも過小適合（訓練データにも合わない）と過学習（訓練には合うが未知データに弱い）が起こります。また、外れ値、スケール、相対誤差、誤差の偏りにも注意が必要です。

この章で一番重要な考え方は、次の一文です。

**回帰問題とは、入力から数値を予測し、その予測値が正解値からどれくらいズレているかを小さくする問題である。**

Transformer やニューラルネットワークも、出力層を変えれば回帰問題に使えます。一方、大規模言語モデルの基本的な事前学習は、次トークンを語彙から選ぶ分類問題として見ることが多いです。分類と回帰の違いを理解しておくと、機械学習モデルが何を予測しているのか、どの損失関数や評価指標を使うべきかが見えやすくなります。
