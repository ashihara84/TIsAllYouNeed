# 第1巻　機械学習の基礎 — *Learning Is All You Need*

教科書シリーズ「**T Is All You Need**」（全8巻）の第1巻です。
最終的に Transformer を自分で（PyTorch で）実装できるようになることを目的としたシリーズの、いちばん最初の入口にあたります。

この巻は、機械学習をまったく前提としない人でも読めるように作られています。数式やコードから入るのではなく、まず「何を入力し、何を出力し、何を正解としているのか」を言葉と図で腑に落とすことを重視します。

## この巻の位置づけ

- **入口（前提）**: なし。機械学習を知らない人でもここから読めます。
- **出口（読了後にできること）**: 教師あり学習・損失・勾配降下を、自分の言葉で説明できる。
- **立ち位置**: この巻は **直感** の巻です。読んで腑に落ちることを優先し、本格的な実装は後の巻で行います（理解を確かめる小さなコードは添えています）。
- **モジュール性**: 機械学習をすでに知っている人は、この巻を飛ばして2巻・3巻から始められます。

## この巻でやらないこと（＝次の巻の仕事）

- 数式で厳密に書く・記号で計算する → **第2巻（数学の基礎）**
- ニューラルネットを自分で実装する → **第3巻（ニューラルネットの基礎）**
- Self-Attention など Transformer の部品を作る → **第5巻**

「Transformer における○○」という橋渡しは各章に散らさず、**第14章（橋専用章）に集約**しています。

## 読み方

1. [第1章 機械学習とは何か](Chapter%201%20What%20Is%20Machine%20Learning.md) から順番に読む
2. 各章の Mermaid 図で概念の流れを確認する
3. 添えられた小さなコードがあれば、手元で少し変えて動かしてみる
4. 各章末の「本章のまとめ」で理解を確認する
5. [第14章 Transformer を読むために必要な機械学習知識](Chapter%2014%20Machine%20Learning%20Knowledge%20Required%20to%20Read%20Transformer.md) まで読んで、Attention の式へ戻る

## 構成（全14章）

- 第1章〜第7章: 機械学習の基本構造、モデルとパラメータ、損失、最適化、データ分割、汎化
- 第8章〜第11章: 分類、回帰、特徴量と表現、確率としての機械学習
- 第12章: ニューラルネットワークへの橋渡し
- 第13章: 機械学習システム全体の流れ
- 第14章: Transformer と『Attention Is All You Need』への接続（橋専用章）

## この教材で重視していること

- 数式より先に、何を入力し、何を出力し、何を正解としているかを見る
- 予測・損失・勾配・パラメータ更新の流れを、何度も別の角度から確認する
- softmax・交差エントロピー・確率といった、後の巻で実体化する概念の **直感** を先に植える
- 章ごとに図とまとめで、同じ概念を繰り返し定着させる
