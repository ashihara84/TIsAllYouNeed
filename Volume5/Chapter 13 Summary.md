# 第13章　まとめ：部品表と7巻への橋

**この章でわかること**

- 作った部品の一覧と、shape のおさらい
- これらが論文の、どの式に対応するか（第6巻への橋）
- 次の巻で統合して動かす（第7巻への橋）

### 13.1　作った部品の一覧と shape

この巻で、Transformer の部品を、すべて自分の手で書きました。

部品表を、shape とともに、振り返りましょう。

```text
□ 重み付き和（第2章）            … Attention の核
□ Q / K / V（第3章）            … x:[B,L,d_model] → Q,K,V:[B,L,d_k]
□ スケール付き内積 Attention（第4章）… softmax(QK^T / sqrt(d_k)) V
□ Self-Attention（第5章）        … [B,L,d_model] → [B,L,d_model]
□ causal mask（第6章）          … 未来を -inf にして重みを0に
□ Multi-Head Attention（第7章）  … d_model を h ヘッドに分割
□ 位置エンコーディング（第8〜9章） … sin/cos と学習版
□ Feed-Forward Network（第10章） … 位置ごとの2層 MLP（d_model→d_ff→d_model）
□ 残差 + LayerNorm（第11章）     … LayerNorm(x + Sublayer(x))
□ Transformer ブロック（第11〜12章）… 上記を組んだ1ブロック
```

これだけの部品を、理由とともに、自分で書けるようになりました。

すべての部品が、入出力 `[B, L, d_model]` をそろえるよう、設計されています。

だから残差で包め、積み重ねられます。

この一貫性が、Transformer が深く積める理由でした。

「入っても出ても同じ形」を守ってきたことが、ここで効いているのです。

### 13.2　これらが論文のどの式に対応するか（第6巻への橋）

次の第6巻では、論文『Attention Is All You Need』を **論文の順** で読みます。

そのとき、この巻で作った部品が、論文の式や図に、一対一で対応していることが、分かります。

あらかじめ、対応表を置いておきます。

```text
論文                                    この巻
──────────────────────────────────────────────────
Scaled Dot-Product Attention      →  第4章
  softmax(QK^T / sqrt(d_k)) V
Multi-Head Attention              →  第7章
masked attention（Decoder）        →  第6章（causal mask）
Positional Encoding（sin/cos）     →  第8〜9章
Position-wise Feed-Forward         →  第10章
Add & Norm                        →  第11章（残差 + LayerNorm）
Encoder/Decoder ブロックの積み重ね   →  第12章（ブロックを並べる）
```

第6巻で論文を開いたとき、新しく学ぶことは、ほとんどありません。

「これは第4章で書いた、あれだ」。

「Add & Norm は、第11章のあれだ」。

すでに作ったものとして、読めるのです。

論文を読むのが、確認作業になります。

これが、部品を先に作ってから論文を読むことの、ねらいです。

初めて論文を読むときの「概念が一度に押し寄せる」重さが、なくなります。

### 13.3　次の巻で統合して動かす（第7巻への橋）

第12章で、部品を「並べてみる」ところで、止めました。

これらを、本当に統合し、動く言語モデルにするのが、第7巻です。

```text
第7巻でやること:
- まず素手（NumPy）で小さなネットの逆伝播を書き、PyTorch の backward() と対比する
- この巻の部品を nn.Module として組み直す
- 文字レベルのデータを用意し、学習ループを回す
- 学習したモデルに、次の文字を生成させる
```

第7巻を終えると、何ができるようになるでしょうか。

「embedding ＋ 位置 ＋ ブロック ＋ 出力層」を統合した、小さな GPT が、実際に文字を吐くところまで、動きます。

この巻で作った部品が、そこで、命を吹き込まれます。

部品を作っただけでは、まだ「動く言語モデル」ではありません。

それらをつなぎ、データを流し、学習させて、はじめて、文字を生成する GPT になります。

その総仕上げが、第7巻です。

### 13.4　本章のまとめ

- この巻で、Transformer の全部品を、理由とともに手で書いた。すべて入出力 `[B, L, d_model]` をそろえてある。
- これらは論文の式・図に一対一で対応する。第6巻では「全部もう知っている」状態で、論文を確認作業として読める。
- 部品の統合（言語モデルとして学習・生成）は第7巻。素手→PyTorch の対比とともに行う。
- 次は第6巻。いよいよ論文『Attention Is All You Need』を、論文の順で読む。
