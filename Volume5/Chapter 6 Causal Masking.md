# 第6章　Causal mask（未来を見ない）

**この章でわかること**

- 言語モデルでは、なぜ未来のトークンを見てはいけないのか
- mask で重みを潰す仕組み（なぜ softmax の前に -inf にするのか）
- causal mask を実装する
- mask 付き Self-Attention の重みを、目で確かめる

### 6.1　言語モデルでは未来のトークンを見てはいけない

第4巻7章で、言語モデルは「これまでの列から、次のトークンを予測する」と学びました。

学習では、各位置で「その次のトークン」を、当てさせます。

ここで、問題が起きます。

前章の Self-Attention は、各トークンが、系列全体（未来も含む）を見ます。

すると、まずいことが起きます。

位置 `i` のトークンが、答えである位置 `i+1` 以降のトークンを、覗き見できてしまうのです。

これでは「カンニング」です。

具体例で見ましょう。

```text
"犬 が 走る 。" で、各位置の次を予測したい
位置「が」で、次（走る）を予測するとき、
  → 「走る」や「。」を見てはいけない（それが答えだから）
```

「が」の次は「走る」だと予測したいのに、もし「走る」を見られたら、答えを見て答えることになります。

それでは、まったく学習になりません。

テストで、答えを見ながら解くようなものです。

だから、各トークンは「自分より前（と自分自身）」だけを見て、「自分より後（未来）」は、見えないようにする必要があります。

これを実現するのが、**causal mask**（因果マスク）です。

「因果（causal）」とは、「過去が未来を決める」という、時間の向きを表しています。

未来から過去へは、影響しない。

その向きを、強制するマスクです。

### 6.2　mask で重みを潰す仕組み

「未来を見ない」は、Attention の重みの上で、実現します。

未来のトークンへの、注目の重みを、強制的に0にすればよいのです。

ただし、ここに、巧妙な工夫があります。

softmax の **後** で0にするのではなく、softmax の **前**（スコアの段階）で、未来の位置を `-無限大` にします。

なぜ、softmax の前なのでしょうか。

理由は、softmax の性質にあります。

softmax は、`-無限大` を入れると、その項の重みを、ちょうど0にしてくれるのです。

なぜなら、`exp(-無限大) = 0` だからです（softmax は exp を使う、第2巻7章）。

しかも、こうすれば、残りの（過去の）項だけで、重みの合計が、きれいに1になります。

もし softmax の後で0にすると、合計が1でなくなってしまい、後で正規化し直す手間がかかります。

softmax の前に `-inf` にすれば、その手間がいりません。

図で見ましょう。

```text
スコア（mask 前）         mask 適用              softmax 後
[ s00 s01 s02 ]          [ s00 -inf -inf ]      [ 1.0  0    0   ]
[ s10 s11 s12 ]    →    [ s10 s11  -inf ]  →  [ 0.4  0.6  0   ]
[ s20 s21 s22 ]          [ s20 s21  s22 ]      [ 0.2  0.3  0.5 ]
```

`(i, j)` のうち、`j > i`（未来）を、`-inf` にします。

結果として、各行（各トークン）は、自分以前の列にしか、重みを持たなくなります。

上の softmax 後の表を見てください。

- 0行目（トークン0）は、自分（0列目）だけに重み1。未来（1, 2列目）は0。
- 1行目（トークン1）は、0列目と1列目に重み。未来（2列目）は0。
- 2行目（トークン2）は、全部に重み（2は最後なので、未来がない）。

上三角（右上の部分）がすべて0、下三角だけ値が残る。

この三角形の形が、causal mask の特徴です。

### 6.3　causal mask を実装する

下三角だけを残すマスクは、`torch.tril`（lower triangle、下三角）で作れます。

```python
import torch

L = 4
mask = torch.tril(torch.ones(L, L))   # 下三角が1、上三角が0
print(mask)
# tensor([[1., 0., 0., 0.],
#         [1., 1., 0., 0.],
#         [1., 1., 1., 0.],
#         [1., 1., 1., 1.]])
```

`torch.ones(L, L)` で、全部1の行列を作り、`torch.tril` で、下三角だけを残します（上三角を0に）。

この `mask` を見てください。

1が立っているところが「見てよい」、0のところが「見てはいけない（未来）」です。

0行目は、0列目だけ1（自分だけ見る）。

3行目は、全部1（最後のトークンなので、全部過去）。

このマスクを使い、`mask == 0` の位置（未来）を、`-inf` にします。

```python
import torch
import torch.nn.functional as F

def causal_attention(Q, K, V):
    L = Q.size(-2)
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / (d_k ** 0.5)   # [..., L, L]

    mask = torch.tril(torch.ones(L, L, device=Q.device))
    scores = scores.masked_fill(mask == 0, float("-inf"))   # 未来を -inf に

    weights = F.softmax(scores, dim=-1)   # 未来の重みは 0 になる
    return weights @ V, weights
```

`masked_fill(mask == 0, float("-inf"))` が、マスクが0の位置（未来）を、`-inf` に置き換えます。

そのあと softmax を取ると、未来への重みが、ちょうど0になります。

第4章の `attention` 関数に、mask の2行を足しただけです。

核は、何も変わっていません。

### 6.4　mask 付き Self-Attention を確かめる

実際に重みを見て、上三角（未来）が0になっていることを、確かめましょう。

```python
import torch

torch.manual_seed(0)
Q = torch.randn(1, 4, 8)
K = torch.randn(1, 4, 8)
V = torch.randn(1, 4, 8)

out, w = causal_attention(Q, K, V)
print(w[0].round(decimals=2))
# 下三角だけに値が入り、上三角は 0 になる
# 例:
# tensor([[1.00, 0.00, 0.00, 0.00],
#         [0.55, 0.45, 0.00, 0.00],
#         [0.31, 0.33, 0.36, 0.00],
#         [0.20, 0.25, 0.27, 0.28]])
```

出力された重みの表を、よく見てください。

- 1行目：`[1.00, 0, 0, 0]`。トークン0 は、自分だけ見ている。
- 2行目：`[0.55, 0.45, 0, 0]`。トークン1 は、0と1を見ている。未来（2, 3）は0。
- 3行目：`[0.31, 0.33, 0.36, 0]`。トークン2 は、0, 1, 2 を見ている。未来（3）は0。
- 4行目：`[0.20, 0.25, 0.27, 0.28]`。トークン3 は、全部見ている（最後なので）。

各行の合計は、すべて1のまま。

未来（上三角）への重みだけが、0になっています。

これで、位置 `i` のトークンは、自分以前しか見られなくなりました。

「次を予測する」学習が、正しく行えます。

カンニングが、できなくなったのです。

第5章の `SelfAttention` モジュールに、この mask 処理を組み込めば、causal Self-Attention の部品が完成します。

これは、第7巻で文字レベル言語モデルを作るときの、まさに中核の部品になります。

### 6.5　本章のまとめ

- 言語モデルの学習では、各トークンが未来（答え）を見るとカンニングになる。未来を隠す必要がある。
- 未来への注目は、softmax の **前** にスコアを `-inf` にすることで、重みをちょうど0にして消す（`exp(-inf)=0`）。
- causal mask は下三角だけ残すマスク（`torch.tril`）。`masked_fill(mask==0, -inf)` で適用する。
- 適用後、各トークンは自分以前にしか重みを持たない（三角形の形）。各行の合計は1のまま。
- これが言語モデルの中核部品になる（第7巻）。
