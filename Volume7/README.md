# 第7巻　PyTorch で Transformer を実装 — *Code Is All You Need*

教科書シリーズ「**T Is All You Need**」（全8巻）の第7巻です。
第5巻で作った部品を統合し、**文字レベル言語モデル（小さな GPT）が次の文字を吐く**ところまで通します。理論（第6巻まで）と実装が出会う、旅の総仕上げです。

## この巻の位置づけ

- **入口（前提）**: 第6巻。
- **出口（読了後にできること）**: 第5巻の部品を統合し、小さな GPT を学習させ、文字を生成できる。
- **立ち位置**: 「素手で組む」と「PyTorch で組む」を一冊の中で前半・後半に分ける。対比が教育効果の核。

## 素手パートの出口（釘で固定）

- NumPy だけで、勾配を手で書いた小さなネットワークを **1個、学習させ切る**（第2章のみ）。
- 直後に同じネットを PyTorch で書き直し、手書きの逆伝播が `loss.backward()` 一行で消える対比を味わう（第3章）。
- Attention まで素手で行かない。自前 autograd フレームワークも作らない（別の山）。

## この巻でやらないこと（＝次の巻の仕事）

- Attention の逆伝播を手で書く（素手は小さな MLP 1個まで）
- 自前 autograd フレームワークを作る
- Decoder-only 化の意義・事前学習・fine-tuning・RLHF → **第8巻**

## 実行環境

```bash
python3 -c "import torch; print(torch.__version__)"
```

すべて CPU で動く小さなモデルです。目的は性能でなく、「自分で組んだ Transformer が文字を生成する」ことです。
