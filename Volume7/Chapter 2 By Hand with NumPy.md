### 2.1　今回作る小さなネットワーク（1個）

題材は、第3巻8章でも使った XOR です。

XOR は、「2つの入力が同じなら0、違うなら1」という問題で、直線では解けないのでした。

だから、隠れ層を持つ、小さな MLP が必要です。

今回は、その逆伝播まで含めて、すべて NumPy で、手書きします。

PyTorch は、一切使いません。

作るネットワークの構造は、こうです。

```text
入力 x （2次元）
  → 線形1（W1, b1）→ ReLU → 隠れ h
  → 線形2（W2, b2）→ 出力 o（2クラスのロジット）
  → softmax → 交差エントロピー損失
```

第3巻で `nn.Linear` や `nn.ReLU` がやってくれていたことを、今回は、全部自分で書きます。

```python
import numpy as np
np.random.seed(0)

# XOR データ
X = np.array([[0.,0.],[1.,1.],[0.,1.],[1.,0.]])   # [4, 2]
y = np.array([0, 0, 1, 1])                          # 正解クラス

# パラメータ（小さくランダム初期化）
W1 = np.random.randn(2, 8) * 0.5;  b1 = np.zeros(8)
W2 = np.random.randn(8, 2) * 0.5;  b2 = np.zeros(2)
```

`W1` は、入力2次元を、隠れ8次元に変換する重みです。

`W2` は、隠れ8次元を、出力2次元（2クラス）に変換する重みです。

第3巻11章で学んだとおり、重みはランダムに初期化しています（全0にしてはいけないのでした）。

### 2.2　順伝播を NumPy で書く

第3巻3〜5章でやったことを、PyTorch なしで、書きます。

```python
def forward(X):
    z1 = X @ W1 + b1          # 線形1   [4, 8]
    h = np.maximum(0, z1)     # ReLU    [4, 8]
    o = h @ W2 + b2           # 線形2   [4, 2] ロジット
    return z1, h, o
```

一行ずつ、確認しましょう。

`z1 = X @ W1 + b1` は、線形変換です（第3巻3章）。

`[4, 2]` の入力に `[2, 8]` の重みを掛けて、`[4, 8]` になります。

`h = np.maximum(0, z1)` が、ReLU です（第3巻4章）。

`np.maximum(0, z1)` は、「0 と z1 を比べて、大きいほう」を取るので、負を0にします。

これが、`nn.ReLU` の正体でした。

`o = h @ W2 + b2` が、2つ目の線形変換で、出力（ロジット）を作ります。

`z1` と `h` も返しているのは、後で逆伝播のときに、使うからです。

### 2.3　損失を計算する

softmax と交差エントロピーを、手で書きます（第2巻7・9章、第3巻5章の回収）。

数値安定化のため、softmax の前に、最大値を引きます（第2巻7章の数値安定化）。

```python
def softmax(o):
    o = o - o.max(axis=1, keepdims=True)   # 数値安定化
    e = np.exp(o)
    return e / e.sum(axis=1, keepdims=True)

def cross_entropy(probs, y):
    n = len(y)
    # 各データの「正解クラスの確率」の -log を平均
    return -np.log(probs[np.arange(n), y] + 1e-9).mean()
```

`softmax` は、第2巻7章で学んだとおりです。

`exp` を取って、合計で割る。

最大値を引いているのは、`exp` が大きくなりすぎないようにする工夫（数値安定化）でした。

`cross_entropy` は、第3巻5章の `-log(正解の確率)` です。

`probs[np.arange(n), y]` は、各データについて、正解クラスの確率を取り出す書き方です。

たとえば、`y = [0, 0, 1, 1]` なら、

- データ0 の、クラス0 の確率、
- データ1 の、クラス0 の確率、
- データ2 の、クラス1 の確率、
- データ3 の、クラス1 の確率、

を取り出します。

その `-log` を、平均します。

`+ 1e-9` は、`log(0)` を避けるための、小さな数です。

### 2.4　勾配を手で導いて書く（連鎖律の回収）

ここが、この章の、山場です。

損失から各パラメータへ、連鎖律（第2巻12章）で、勾配を後ろ向きに伝えます。

PyTorch なら `loss.backward()` の一行ですが、それを、手で書きます。

ここで、softmax ＋ 交差エントロピーの組み合わせには、有名な、美しい結果があります。

出力ロジットに対する勾配が、とても簡単な形になるのです。

```text
出力ロジットに対する勾配 = (softmax の出力) - (正解の one-hot)
```

なぜこうなるかの導出は、第2巻の範囲を超えるので、ここでは結果を使います。

この美しい形が、逆伝播の出発点です。

```python
def backward(X, z1, h, o, y):
    n = len(y)
    probs = softmax(o)

    # 出力（ロジット）に対する勾配： softmax - onehot(y)
    do = probs.copy()
    do[np.arange(n), y] -= 1
    do /= n                       # [4, 2]

    # 線形2 の勾配
    dW2 = h.T @ do                # [8, 2]
    db2 = do.sum(axis=0)         # [2]

    # 隠れ層へ伝える
    dh = do @ W2.T               # [4, 8]
    dz1 = dh * (z1 > 0)          # ReLU の勾配（正のところだけ通す）

    # 線形1 の勾配
    dW1 = X.T @ dz1              # [2, 8]
    db1 = dz1.sum(axis=0)       # [8]

    return dW1, db1, dW2, db2
```

一行ずつ、何をしているかを、見ましょう。

`do = probs.copy(); do[np.arange(n), y] -= 1` が、`softmax - onehot(y)` です。

正解クラスの位置だけ、1を引いています。

`dW2 = h.T @ do` が、線形2 の重みの勾配です。

第2巻12章の連鎖律で、「出力の勾配 `do` を、入力 `h` と組み合わせる」と、こうなります。

`dh = do @ W2.T` が、勾配を、隠れ層へ伝える計算です。

線形層を、逆向きに通すと、重みの転置 `W2.T` を掛けることになります。

`dz1 = dh * (z1 > 0)` が、ReLU の逆伝播です。

ReLU は「正はそのまま、負は0」だったので、その勾配は「正だったところだけ、勾配を通す（負だったところは0）」になります。

`(z1 > 0)` は、`z1` が正のところが True(1)、負のところが False(0) になるので、これを掛けると、まさに「正のところだけ通す」になります。

これだけの量を、PyTorch は `backward()` 一行で、肩代わりしてくれていたのです。

何十行もの、連鎖律の計算。

それが、一行になる。

そのありがたみが、自分で書いてみると、身にしみます。

### 2.5　一周を回して学習させ切る

順伝播・損失・逆伝播が、そろいました。

あとは、勾配降下で更新する一周を、繰り返します（第3巻7章の学習ループを、手で）。

```python
lr = 0.5
for step in range(2000):
    z1, h, o = forward(X)
    probs = softmax(o)
    loss = cross_entropy(probs, y)

    dW1, db1, dW2, db2 = backward(X, z1, h, o, y)

    # 勾配降下（手で更新）
    W1 -= lr * dW1;  b1 -= lr * db1
    W2 -= lr * dW2;  b2 -= lr * db2

    if step % 400 == 0:
        print(f"step {step:4d}  loss {loss:.4f}")

# 学習結果
_, _, o = forward(X)
pred = o.argmax(axis=1)
print("予測:", pred.tolist(), " 正解:", y.tolist())   # [0,0,1,1] になれば成功
```

ループの中身は、第3巻7章の `forward → loss → backward → step` の骨格、そのままです。

違うのは、`backward` も `step`（更新）も、自分で書いた関数・式である、という点です。

`W1 -= lr * dW1` が、勾配降下の更新（第3巻6章の「重み − 学習率 × 勾配」）です。

実行すると、損失が下がっていきます。

```text
step    0  loss 0.7251
step  400  loss 0.6800
step  800  loss 0.4521
step 1200  loss 0.1203
step 1600  loss 0.0382
予測: [0, 0, 1, 1]  正解: [0, 0, 1, 1]
```

損失が下がり、最後に予測が `[0, 0, 1, 1]` になりました。

**NumPy だけで、勾配を手書きした小さなネットを、1個、学習させ切った** のです。

これが、素手パートの出口です。

順伝播・損失・逆伝播・更新の一周を、自分の手が、全部触りました。

この感触が、次章で PyTorch に移ったときの、深い納得につながります。

### 2.6　本章のまとめ

- XOR を解く小さな MLP を、NumPy だけで、逆伝播まで手書きして、学習させ切った。
- softmax＋交差エントロピーの出力勾配は `softmax - onehot(y)` という、簡単な形になる。
- 勾配は連鎖律で後ろへ伝える（第2巻12章・第3巻6章の具体化）。ReLU の逆伝播は `dh * (z1 > 0)`（正のところだけ通す）。
- この手書きの逆伝播ぜんぶを、PyTorch は `loss.backward()` 一行で肩代わりする。次章でそれを体感する。
