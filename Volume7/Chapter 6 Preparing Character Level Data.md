# 第6章　データを用意する（文字レベル）

**この章でわかること**

- テキストを文字 ID 列にする（第4巻の回収）
- 入力と「次の文字」ターゲットを作る
- バッチとブロック長
- DataLoader 的な仕組みを組む

### 6.1　テキストを文字 ID 列にする（第4巻の回収）

文字レベル言語モデルでは、トークン＝文字です（第4巻3章の文字単位トークン化）。

なぜ文字レベルにするのか。

実装が、いちばん素直だからです。

サブワード分割（BPE など）は、現代の主流ですが、仕組みが複雑です（第8巻で扱います）。

この巻では、「動かす」ことに集中したいので、いちばん単純な文字単位を、選びます。

手元のテキストから、文字の語彙を作り、文字 ID 列に、変換します。

```python
text = "犬が走る。猫も走る。犬は歩く。"   # 実際はもっと長いテキストを使う

chars = sorted(set(text))
vocab_size = len(chars)
stoi = {c: i for i, c in enumerate(chars)}   # 文字 -> ID
itos = {i: c for c, i in stoi.items()}       # ID -> 文字

def encode(s): return [stoi[c] for c in s]
def decode(ids): return "".join(itos[i] for i in ids)

import torch
data = torch.tensor(encode(text), dtype=torch.long)
print(vocab_size, data[:10])
```

第4巻4章で書いた encode/decode と、同じ仕組みです。

`set(text)` で文字の種類を取り出し、それに番号を振る。

`encode` で文字列を ID 列に、`decode` で ID 列を文字列に戻す。

`data` は、テキスト全体を文字 ID に変換した、長い1次元のテンソルです。

「犬が走る。猫も走る。…」が、`[0, 3, 5, ...]` のような、長い数の列に、なります。

### 6.2　入力と「次の文字」ターゲットを作る

言語モデルの学習は、次トークン予測でした（第4巻7章）。

文字レベルなら、「次の文字」を当てます。

ここが、この章の、肝です。

**ターゲットは、入力を1文字だけ後ろにずらしたもの** です。

第4巻7章で学んだ「テキストの1つ後ろが、そのまま正解」を、思い出してください。

具体例で、確かめましょう。

```text
テキスト:  犬 が 走 る 。
入力 x  :  犬 が 走 る
正解 y  :  が 走 る 。      （x を1つ左にずらした形）
```

各位置で、「その次の文字」が正解です。

- 「犬」の次は「が」
- 「が」の次は「走」
- 「走」の次は「る」
- 「る」の次は「。」

`y` が、`x` を1つ左にずらしたものに、なっています。

これで、各位置で「次の文字」を予測する、学習データができます。

長いテキストから、ある長さ（ブロック長）の連続した区間を、切り出します。

そして、入力 `x` と、その1つずれの `y` を、作ります。

```python
block_size = 8   # 一度に見る文字数（系列長 L）

def get_batch(data, batch_size, block_size):
    # ランダムな開始位置を batch_size 個選ぶ
    ix = torch.randint(len(data) - block_size - 1, (batch_size,))
    x = torch.stack([data[i:i+block_size] for i in ix])        # [B, L]
    y = torch.stack([data[i+1:i+block_size+1] for i in ix])    # [B, L] 1つずれ
    return x, y
```

`ix` で、ランダムな開始位置を選びます。

`x` は、その位置から `block_size` 個。

`y` は、その1つ後ろから `block_size` 個。

`y` が `x` の1つ後ろにずれているのが、要点です。

### 6.3　バッチとブロック長

2つの大きさを、区別しましょう。

```text
block_size（L）  : 一度にモデルに見せる連続文字数（系列長）。文脈の長さ。
batch_size（B）  : 何個の区間をまとめて流すか。並列処理の単位。
```

`block_size` は、「文脈の長さ」です。

これが8なら、モデルは「直前の8文字」を見て、次を予測します。

`batch_size` は、「まとめて流す数」です（第3巻3章のバッチ）。

`get_batch` は、`[B, L]` の入力と、同じ shape のターゲットを、返します。

第4巻6章で「系列は `[batch, L]` の ID、embedding 後に `[batch, L, d_model]`」と整理しました。

その入口が、ここです。

```python
x, y = get_batch(data, batch_size=4, block_size=8)
print(x.shape, y.shape)   # torch.Size([4, 8]) torch.Size([4, 8])
```

`[4, 8]` の入力と、`[4, 8]` のターゲット。

4区間、各8文字、というわけです。

### 6.4　DataLoader 的な仕組み

本格的なプロジェクトでは、PyTorch の `DataLoader` を使います。

しかし、文字レベルの小さなモデルでは、上の `get_batch` を、ループの中で毎回呼ぶ、簡単な仕組みで、十分です。

学習ループ（第11章）の中で、ステップごとに、新しいバッチを、ランダムに切り出します。

```python
# 学習ループの中で（イメージ）
# for step in range(...):
#     x, y = get_batch(data, batch_size, block_size)
#     ...（forward → loss → backward → step）
```

毎ステップ、テキストの違う場所から、ランダムに切り出す。

そうやって、テキスト全体を、まんべんなく学習します。

データの準備が、できました。

次章で、この `[B, L]` の ID を、embedding ＋ 位置エンコーディングで、`[B, L, d_model]` にし、モデルへ流す入口を、作ります。

### 6.5　本章のまとめ

- 文字レベルでは文字＝トークン。文字の語彙を作り、テキストを文字 ID 列にする（第4巻の回収）。実装が素直なので採用。
- ターゲットは入力を1文字後ろにずらしたもの。各位置で「次の文字」が正解（自己教師、第4巻7章）。
- `block_size`（系列長 L、文脈の長さ）と `batch_size`（B、まとめて流す数）を区別。`get_batch` は `[B, L]` の x と1つずれの y を返す。
- 小さなモデルでは `get_batch` をループで呼ぶ簡単な仕組みで十分。毎回ランダムな場所から切り出す。
