# 第12章　まとめ：5巻への橋

**この章でわかること**

### 12.1　この巻でたどった道のり

第4巻では、言語を扱うための土台を、一通り組み立てました。

たどった道を、振り返りましょう。

```text
言語を数にする（記号 → ID → ベクトル）          … 第2章
  ↓
トークン化・語彙・ID                            … 第3〜4章
  ↓
embedding：ID を意味の載るベクトルにする          … 第5章
  ↓
系列と文脈：順序が意味を持ち、文脈で意味が決まる   … 第6章
  ↓
言語モデル：次トークン予測という巨大な分類問題     … 第7章
  ↓
n-gram → ニューラル言語モデル → 固定窓の限界      … 第8章
  ↓
RNN：状態を持ち越す。だが3つの辛さ              … 第9〜10章
  ↓
Attention：全トークンを直接見比べ、並列に文脈を混ぜる … 第11章
```

前半で「言語を数にする」山を、後半で「RNN の辛さから Attention へ」の山を、登りました。

2つの山を越えて、Transformer の入口まで、たどり着いたのです。

### 12.2　いま語れるようになったこと

この巻の出口は、「RNN は何が辛くて、Attention が何を足したかを語れる」ことでした。

いま、それが言えるはずです。

確認してみましょう。

- RNN は情報を1ステップずつ状態経由で運ぶため、長距離が薄まり、勾配が消え、逐次で並列化できない。
- Attention は全トークンを直接見比べ、内積で相性を測り、softmax の重みで重み付き和を取って、文脈を混ぜる。これにより長距離・勾配・並列の3つを同時に解く。

これが、すらすら言えれば、この巻は達成です。

この「なぜ Attention なのか」を腑に落としたことが、次の巻でのいちばんの武器になります。

なぜでしょうか。

仕組みを作るとき、「何のためにこの計算をしているのか」が、分かっているからです。

ただ「こう計算する」と覚えるのと、「RNN の辛さを解くために、こう計算する」と理解するのとでは、深さがまったく違います。

### 12.3　なぜ次に Attention の部品を作るのか

第11章で、Attention の核を、「内積で相性を測り、softmax で重みにして、重み付き和で混ぜる」と、動機のレベルでつかみました。

しかし、まだ作ってはいません。

仕組みのイメージは持ちましたが、コードは書いていません。

次の第5巻「Transformer の構成要素」では、これを実際の部品として、一つずつ手で書きます。

```text
第5巻で作る部品:
- Q / K / V という役割分担
- スケール付き内積 Attention（softmax(QK^T / sqrt(d_k))V）
- Self-Attention / causal mask
- Multi-Head Attention
- 位置エンコーディング（この巻で残した「順序」の課題を解く）
- Feed-Forward Network
```

そして、それらを、第3巻で仕込んだ残差接続と LayerNorm で包めば、Transformer のブロックになります。

第3巻の `LayerNorm(x + Sublayer(x))` の、`Sublayer` の中身が、ついに埋まるのです。

第3巻で「中身は第5巻で」と保留していた、あの `Sublayer` が、Attention として、姿を現します。

### 12.4　次の巻への橋

これで、Transformer を作るための準備が、整いました。

シリーズ全体の中での、いまの位置を確認しましょう。

```text
第1巻：機械学習の直感
第2巻：数学（ベクトル・内積・softmax・微分）
第3巻：ニューラルネットを書く（残差接続・LayerNorm を仕込む）
第4巻：言語をベクトルにし、Attention の動機を得る（本書）
  ↓
第5巻：Attention の部品を、最適な順で一つずつ作る
```

第1〜3巻で土台を作り、第4巻で言語と動機を得た。

すべての準備が、整いました。

第5巻では、論文の提示順ではなく、**教えるのに最適な順** で、部品を組み立てます。

動機（この巻）を持った状態で部品を作り、第6巻で論文を読むと、「全部もう知っている」状態で、論文に向き合えます。

次は、いよいよ Attention を、自分の手で書きはじめます。

この巻で得た「なぜ」を、胸に抱いて、進みましょう。
