# 用語集（第4巻）

- **トークン（token）**: 言語モデルが扱う最小単位。文字・単語・サブワードのいずれか。
- **トークン化（tokenization）**: 文章をトークンの列に切り分けること。
- **サブワード**: 単語より細かく、文字より大きい単位。よく出る語はまるごと、珍しい語は部分に分ける。現代の主流。
- **BPE（Byte Pair Encoding）**: 頻出する隣接ペアを繰り返し結合してサブワード語彙を作る方法。詳細は第8巻。
- **語彙（vocabulary）**: モデルが知っているトークンの全集合。
- **未知語（unknown token）**: 語彙に含まれないトークン。サブワードはこれを和らげる。
- **ID**: 語彙の中でのトークンの背番号。トークン→ID がエンコード、ID→トークンがデコード。
- **特殊トークン**: `<bos>`（開始）・`<eos>`（終了）・`<pad>`（長さそろえの詰め物）など、単語以外の制御用トークン。
- **one-hot 表現**: そのトークンの位置だけ1、他は0のベクトル。巨大で意味が載らない。
- **embedding（埋め込み）**: ID を、意味の近さを載せられる密なベクトルに変換すること。embedding 行列の行を引く操作。
- **embedding 行列**: `[語彙サイズ, d_model]` の行列。各行が1トークンのベクトル。学習で決まるパラメータ。
- **d_model**: 1トークンの表現ベクトルの次元。Transformer の中を流れるベクトルの幅。
- **系列（sequence）**: 順序が意味を持つ、要素の並び。言語は典型的な系列。
- **文脈（context）**: あるトークンの意味を決める、周りのトークン。同じ語でも文脈で意味が変わる。
- **パディング（padding）**: バッチ処理のため、短い系列を `<pad>` で埋めて長さをそろえること。埋めた場所は後で無視（マスク）する。
- **言語モデル（language model）**: これまでのトークン列から、次のトークンの確率分布を出すモデル。
- **次トークン予測**: 言語モデルの中心タスク。テキストの1つ後ろがそのまま正解になる（自己教師）。
- **n-gram**: 直前 n-1 個から次を予測する古典的言語モデル。確率は頻度の数え上げで求める。
- **固定窓モデル**: 直前の決まった個数のトークンだけを見るニューラル言語モデル。窓の外は見えない。
- **RNN（再帰型ニューラルネット）**: 状態を1ステップずつ持ち越して系列を処理するモデル。この巻では実装せず動機づけに使う。
- **LSTM / GRU**: ゲートで情報の「保つ／忘れる」を調整した RNN の改良版。長い文脈を扱いやすい。
- **長距離依存**: 系列の中で遠く離れた要素どうしの関係。RNN は運ぶ途中で薄まる。
- **Attention（注意機構）**: 各トークンが全トークンを直接見比べ、内積で相性を測り、softmax の重みで重み付き和を取って文脈を混ぜる仕組み。実装は第5巻。
- **注目の重み（attention weight）**: どのトークンにどれだけ注目するかを表す、合計1の重み。
