# 第5章　Attention の節を読む

**この章でわかること**

- Scaled Dot-Product Attention の式（第5巻4章の対応）
- `sqrt(d_k)` の説明を、著者はどう書いているか
- mask の扱い

### 5.1　Scaled Dot-Product Attention の式

論文は「Scaled Dot-Product Attention」という小節で、中心式を提示します。

第5巻4章で、私たちが手で書いた、あの式です。

```text
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V
```

論文は、これを、こう説明します。

「Query と全 Key の内積を取り、各々を sqrt(d_k) で割り、softmax を適用して、Value の重みを得る」。

第5巻4章で、一段ずつ作った流れを、思い出してください。

```text
QK^T で相性     → sqrt(d_k) でスケール → softmax で重み → V の重み付き和
```

論文の説明と、完全に一致します。

あなたが手で書いた手順が、そのまま、論文に書いてあるのです。

論文はさらに、Attention には大きく2種類（加法的 Attention と内積 Attention）がある、と触れます。

そして、この論文は、内積（dot-product）型を選んだ、と述べます。

理由は、内積型のほうが、行列積で効率よく・高速に計算できるからです。

第4巻11章・第5巻4章で見た「1回の行列積で、全ペアを並列計算」という利点が、著者の言葉で、裏づけられます。

### 5.2　`sqrt(d_k)` の説明を著者はどう書いているか

論文は、なぜ `sqrt(d_k)` で割るのかを、はっきり説明しています。

要約すると、こうです。

```text
- d_k が大きいと、内積 QK^T の値が大きくなりやすい。
- 値が大きいと softmax が極端にとがり、勾配が非常に小さくなる領域に入る。
- それを防ぐため、内積を sqrt(d_k) で割って、スケールを戻す。
```

これは、第5巻4章で、私たちが説明した理由と、まったく同じです。

第5巻では、`softmax([20,10,0])` が `[0.9999, ...]` のようにとがる例で、確かめました。

論文には、それに加えて、もう一歩踏み込んだ根拠が、添えられています。

「内積の分散が、d_k に比例して大きくなるから」。

第2巻13章で分散を学んだあなたなら、この根拠も、読めます。

並べてみましょう。

```text
第5巻：sqrt(d_k) で割ると softmax がとがりすぎず安定する（実装の理由）
論文 ：内積の分散が d_k に比例する。だから sqrt(d_k) で割って戻す（統計的な根拠）
```

実装の理由を、自分でつかんでいたから、論文の統計的な根拠も、「ああ、そういうことか」と、すっと入ってきます。

### 5.3　mask の扱い

論文は、Attention の中で、mask に触れます。

Decoder の Self-Attention では、各位置が未来の位置を見ないように、softmax の入力で、該当箇所を `-無限大` 相当にする、と述べます。

第5巻6章で、私たちは、まさにこれを実装しました。

`masked_fill(mask == 0, float("-inf"))` で未来を `-inf` にし、softmax で重みを0にする、あの処理です。

論文の説明と、自分の書いたコードが、ぴたりと重なります。

```text
論文：未来の位置を softmax 前にマスクして、不正な接続を防ぐ
第5巻6章：scores.masked_fill(mask == 0, -inf) → softmax で重み 0
```

「なぜ softmax の前なのか」も、あなたは知っています。

`exp(-inf) = 0` だから、softmax の前に `-inf` にすると、重みがちょうど0になり、残りで合計1になる、という、あの工夫です（第5巻6章）。

この節は、第5巻4章・6章を「論文の言葉で確認する」だけの章です。

新しいことは、`sqrt(d_k)` の統計的な根拠くらいで、あとはすべて、手の内にあります。

### 5.4　本章のまとめ

- 論文の中心式 `softmax(QK^T / sqrt(d_k)) V` は、第5巻4章で手で書いた式そのもの。
- 内積型 Attention を選んだのは、行列積で高速・並列に計算できるから（第4巻11章の利点）。
- `sqrt(d_k)` で割る根拠は「内積の分散が d_k に比例するから」。第5巻の実装理由に、統計的裏づけが付く。
- mask の扱いは、第5巻6章の `masked_fill(..., -inf)`（softmax 前に -inf）と一致する。
