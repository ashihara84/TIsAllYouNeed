# 第2章　Abstract と Introduction を読む

**この章でわかること**

- なぜ再帰も畳み込みも捨てたのか
- Attention だけで系列を扱う、という主張
- 当時の文脈（何に対する改善か）

### 2.1　Abstract の主張を自分の言葉で

論文の Abstract（要旨）は、主張を、一段落に凝縮しています。

要点を、自分の言葉でまとめると、こうなります。

```text
- 当時の主流の系列変換モデルは、再帰（RNN）や畳み込み（CNN）を使い、
  そこに Attention を補助的に組み合わせていた。
- この論文は、再帰も畳み込みも使わず、Attention だけ に基づく新しい構造
  「Transformer」を提案する。
- 結果として、翻訳タスクで高い品質を、より少ない学習時間（並列化のしやすさ）で達成した。
```

第4巻で「RNN の辛さ」と「Attention が足したもの」を腑に落としたあなたには、この主張の重みが、分かります。

一つずつ、第4巻と結びつけてみましょう。

「再帰を捨てる」とは、第4巻10章で見た、逐次処理の足かせを外す、ということです。

RNN の「前から順にしか計算できない」を、やめるのです。

「Attention だけ」とは、第4巻11章の「全トークンを直接見比べ、並列に計算する」を、補助ではなく主役にする、ということです。

Abstract の短い一段落に、あなたが第4巻で学んだことが、すべて詰まっています。

### 2.2　Attention だけで系列を扱うという主張

タイトル "Attention Is All You Need" の主張は、文字どおり「（系列を扱うのに）必要なのは Attention だけだ」です。

当時としては、大胆でした。

なぜなら、再帰こそが、系列処理の本流だと考えられていたからです。

「系列を扱うなら RNN」というのが、当時の常識でした。

その常識に、「いや、Attention だけでいい」と挑んだのが、この論文です。

なぜ「だけ」で足りると言えるのか。

第4巻11章で、私たちはすでに、その理由を語れます。

```text
- 長距離依存：全トークンを直接見比べるので、距離に関係なく結べる
- 勾配      ：経路が短く、深い時間展開に頼らない
- 並列性    ：全トークン対の相性を1回の行列積で同時に計算できる
```

論文は、この「Attention だけで、しかもその方が良い」を、翻訳タスクの結果で、裏づけていきます（第10章）。

主張があり、その主張を結果で支える。

論文の、基本の構造です。

### 2.3　当時の文脈（何に対する改善か）

論文を正しく読むには、「何に対する改善なのか」という、当時の文脈を、押さえることが大切です。

2017 年当時、機械翻訳などの系列変換では、どういうモデルが主流だったでしょうか。

RNN（特に LSTM）を Encoder–Decoder にした構造が、主流でした。

そこに Attention を「Decoder が Encoder の出力の、どこを見るか」という、補助機構として加えるのが、一般的でした。

つまり、当時の Attention は、**脇役** だったのです。

```text
当時の主流 : RNN/LSTM（主役） + Attention（脇役）
この論文   : Attention（主役）、RNN/CNN は無し
```

また、CNN を使って並列性を上げる試み（系列を畳み込みで処理する）も、ありました。

しかし CNN は、遠く離れた位置を結ぶのに、層を重ねる必要があり、長距離依存に、弱さがありました。

論文は、Abstract と Introduction で、こうした既存手法の限界（逐次性、長距離の経路の長さ）を指摘します。

そして、それらをまとめて解く構造として、Transformer を位置づけます。

この「脇役だった Attention を、主役に据えた」という転換が、論文のいちばんの新しさです。

第5巻で部品として作った Self-Attention は、まさに、この主役の Attention でした。

あなたは、当時の研究者が「主役にしよう」と決めた、その部品を、すでに自分で書いているのです。

### 2.4　本章のまとめ

- Abstract の主張：再帰も畳み込みも使わず、Attention だけに基づく Transformer を提案し、翻訳で高品質を少ない学習時間で達成した。
- 「Attention だけで足りる」理由は、第4巻11章で語れる（長距離・勾配・並列）。
- 当時の文脈：RNN/LSTM が主役で、Attention は脇役だった。この論文はそれを逆転させた。
- CNN による並列化の試みもあったが、長距離依存に弱かった。Transformer はそこも解く。
