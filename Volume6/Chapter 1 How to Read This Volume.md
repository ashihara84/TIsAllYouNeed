# 第1章　この巻の読み方

**この章でわかること**

- 「全部もう知っている」状態で論文を開く、とはどういうことか
- 第5巻の部品と論文の式の、対応表
- この巻で見るべきは「提示順」と「設計理由」であること

### 1.1　「全部もう知っている」状態で論文を開く

この巻では、いよいよ論文『Attention Is All You Need』(Vaswani et al., 2017) を、**論文の順** で読みます。

ふつう、論文を初めて読むのは、大変です。

新しい概念が一度に押し寄せ、式の意味をつかむだけで、精一杯になります。

「Self-Attention って何だ」「sqrt(d_k) はどこから出てきた」「Multi-Head とは」。

一つ理解しようとすると、別の分からないものが出てきて、迷子になります。

しかし、あなたはもう、違います。

第5巻で、Self-Attention も、Multi-Head も、位置エンコーディングも、FFN も、残差＋LayerNorm も、すべて自分の手で書きました。

理由とともに、書きました。

だから、論文を読むときの体験が、まったく違います。

```text
ふつうの初読 : 概念を理解しながら、式を追う（重い）
あなたの読み : すでに作った部品を、論文の言葉で確認する（軽い）
```

だからこの巻は、**薄く鋭く** いきます。

新しい部品は、一つも教えません。

論文を読みながら、「これは第5巻のあれだ」と確認し、著者が何をどう提示し、なぜその設計にしたのかだけを、見ます。

これが、この巻のねらいです。部品を先に作ってから論文を読むからこそ、初読の重さなしに、設計と理由だけを見ていけます。

> 著者の主張や式の意味は、自分の言葉で言い換えて確認します。論文本文の引用は最小限にとどめ、手元に論文（arXiv:1706.03762）を開いて読み合わせることを前提にします。

### 1.2　第5巻の部品と論文の式の対応表

読み始める前に、第5巻13章で作った対応表を、もう一度、手元に置きます。

これが、論文を読むときの「地図」です。

```text
論文の構成要素                          第5巻
──────────────────────────────────────────────────
Scaled Dot-Product Attention      →  第4章（中心式）
Multi-Head Attention              →  第7章
masked attention（Decoder 側）     →  第6章（causal mask）
Positional Encoding（sin/cos）     →  第8〜9章
Position-wise Feed-Forward         →  第10章
Add & Norm                        →  第11章（残差 + LayerNorm）
Encoder / Decoder スタック          →  第12章（ブロックを積む）
```

論文を読みながら、各節がこの表のどれに当たるかを、つねに確認してください。

「いま読んでいる節は、第5巻の何章で作ったものか」。

それを意識するだけで、論文が、ぐっと読みやすくなります。

新しいものは、ほとんど出てきません。

出てくるのは、せいぜい「著者がなぜその設計を選んだか」という理由づけくらいです。

### 1.3　見るべきは「提示順」と「設計理由」

部品の中身を知っているあなたが、論文から新しく得るものは、主に2つです。

**1. 提示順（どういう順で、何を強調して語るか）。**

論文は、限られた紙面で、主張を伝えるために、情報を取捨選択し、順序を組み立てています。

第5巻の「教える順」と、論文の「主張する順」が、どう違うか。

それを見ると、論文の意図が、見えてきます。

たとえば、第5巻では Attention を「単純な核から」積み上げました。

論文は、いきなり完成形を提示します。

この違いに、「読者にどう伝えたいか」の工夫が、現れています。

**2. 設計理由（なぜその選択をしたか）。**

なぜ再帰も畳み込みも捨てたのか。

なぜ `sqrt(d_k)` で割るのか。

なぜ Multi-Head なのか。

第5巻では「こうする」と作りましたが、論文には、著者自身の「なぜ」が書かれています。

特に「Why Self-Attention」の節（第8章で扱います）は、この巻の核です。

```text
第5巻で得たもの : 部品が「どう動くか」（実装）
この巻で得るもの : 著者が「なぜそう設計したか」「どう提示するか」
```

実装は手の内にある。

だからこそ、設計の「なぜ」に、集中して向き合えるのです。

### 1.4　本章のまとめ

- この巻は論文を「論文の順」で読む、回収巻。第5巻で全部品を作ったので、新しい部品は学ばない。
- 第5巻の部品と論文の式の対応表を、地図として、各節が何に当たるかを確認しながら読む。
- 得るべきは「提示順（どう語るか）」と「設計理由（なぜその選択か）」。中身はすでに知っている。
- 薄く鋭く読む。論文本文（arXiv:1706.03762）を手元に開いて、読み合わせる前提。
