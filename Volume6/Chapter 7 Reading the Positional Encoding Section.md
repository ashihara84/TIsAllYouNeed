# 第7章　位置エンコーディングの節を読む

**この章でわかること**

- なぜ位置エンコーディングが要るのか（論文の論理）
- sin / cos を選んだ理由
- 学習埋め込みとの比較を、著者はどう述べたか

### 7.1　なぜ位置エンコーディングが要るのか（論文の論理）

論文は、位置エンコーディングの小節で、まず、こう述べます。

「このモデルには再帰も畳み込みもないので、系列の順序を利用するには、位置の情報を明示的に注入する必要がある」。

これは、第5巻8章で、私たちが確認したことそのものです。

Attention は順序を知らない（入力を集合として見る）ので、順序を別に与えなければならない。

論文の論理と、第5巻の説明が、一致します。

ここで、第4巻11章の予告を、思い出してください。

第4巻11章の最後で、「Attention の残る課題は順序」と、予告しました。

その課題が、ここで、論文の言葉として、現れます。

「再帰がないから、順序を別に入れる必要がある」。

これは、第4巻で気づき、第5巻で対処した、まさにその問題です。

論文を読みながら、自分がたどってきた道を、確認できます。

### 7.2　sin / cos を選んだ理由

論文は、位置エンコーディングとして、sin / cos 関数を使います（第5巻8〜9章で実装したもの）。

式も、第5巻で書いたとおりです。

```text
PE(pos, 2i)   = sin( pos / 10000^(2i/d_model) )
PE(pos, 2i+1) = cos( pos / 10000^(2i/d_model) )
```

著者が sin/cos を選んだ理由として、挙げるのは、主に次の点です。

```text
- 任意の固定のずれ k に対して、PE(pos+k) を PE(pos) の線形変換で表せる。
  → モデルが「相対的な位置関係」を学びやすいと期待できる。
- 学習データより長い系列にも、関数として値を計算できる（外挿の可能性）。
```

第5巻8章で述べた2点が、まさに、著者の選択理由です。

「位置 a と位置 a+k の関係が、波の性質から一定パターンで表れる」。

「学習より長い系列にも、外挿しやすい」。

第5巻で「時計の針」のたとえを使って、この性質を、つかみました。

その直感が、論文の選択理由を、読み解く助けになります。

### 7.3　学習埋め込みとの比較を著者はどう述べたか

論文は、学習する位置埋め込み（learned positional embedding）も、試しています。

そして、sin/cos と、ほぼ同等の性能だった、と報告しています。

そのうえで、sin/cos を採用した理由として、学習データより長い系列に、外挿できる可能性を、挙げています。

```text
論文：学習埋め込みも sin/cos もほぼ同等の性能だった。
      外挿の可能性から、sin/cos を採用した。
```

第5巻8〜9章で「sin/cos は外挿しやすい、学習版は柔軟だが学習した長さまで」と整理し、両方を実装しました。

論文の比較は、その整理を、裏づけます。

「どちらも性能は同じくらい。でも外挿のために sin/cos」という著者の判断が、あなたの理解と、ぴたり合います。

ここで一つ、現代との橋渡しを、しておきましょう。

論文以後、位置情報の与え方は、活発に研究され、相対位置を直接扱う手法（RoPE など）が、広く使われるようになりました。

これは、第8巻で触れます。

論文の sin/cos は、その出発点として、位置づけられます。

「最初の一歩」だった、というわけです。

### 7.4　本章のまとめ

- 再帰も畳み込みもないので、順序の情報を明示的に注入する必要がある（第5巻8章・第4巻11章と一致）。
- 著者が sin/cos を選んだ理由は、相対位置を線形に表せること、長い系列への外挿の可能性（第5巻8章で得た直感）。
- 学習埋め込みもほぼ同等の性能。外挿の可能性から sin/cos を採用した。
- 位置情報の手法はその後発展した（RoPE など）。論文の sin/cos はその出発点。詳細は第8巻。
