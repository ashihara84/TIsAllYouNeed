# 第2巻　数学の基礎 — *Math Is All You Need*

教科書シリーズ「**T Is All You Need**」（全8巻）の第2巻です。
Transformer の式を読み、のちに自分で実装するために必要な数学を、順番に積み上げます。

いきなり Attention の式へ進むのではなく、数・スカラー・ベクトル・行列・内積・線形変換・softmax・確率分布・損失関数・微分・勾配降下法・連鎖律・正規化を一つずつ確かめ、最後に Attention の中心式を **読んで一度確かめる** ところまで進みます。

## この巻の位置づけ

- **入口（前提）**: 第1巻、または機械学習の素養。数学が分かっている人はこの巻を飛ばせます。
- **出口（読了後にできること）**: ベクトル・行列・内積・softmax・微分が記号で怖くなくなる。**証明より「形」と「意味」** を重視し、コードで **一度** 確かめられる。
- **立ち位置**: 数学を理解し、コードで一度確かめる巻です。**作り込みません**。

## この巻でやらないこと（＝次の巻の仕事）

- Self-Attention を **モジュール化** する／Transformer 風 **ブロックを組む** → **第5巻**
- 部品を統合して動くモデルにする → **第7巻**
- ニューラルネットを設計して学習させ切る → **第3巻**

この巻での実装は、数式が正しいことを **一度確かめる** ためだけに留めます。第14章 14.8 と第15章 15.6 は、滑りやすい「ちょうつがい」です。本文中の注記のとおり、ここは *読む／確かめる* 段階であって *作る* 段階ではありません。

## 構成（全16章）

- 第1章〜第3章: Transformer に数学が必要な理由、数・スカラー・ベクトル

- 第16章: 自己チェックリストと次の巻への橋渡し

## 第1巻との関係（スパイラル）

softmax・確率・交差エントロピー・微分・勾配降下は、第1巻にも登場します。これは重複ではなく、意図した **スパイラル** です。第1巻で **直感** を植え、本書で **形と意味＋コードでの確認** に落とします。

## 実行環境

章内のサンプルコードは、Python と PyTorch で動かすことを想定しています。

```bash
python3 -c "import torch; print(torch.__version__)"
```

コードは小さな確認用なので、GPU は不要です。CPU だけで動くようにしています。
