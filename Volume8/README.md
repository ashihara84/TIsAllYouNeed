# 第8巻　Transformer から現代の LLM へ — *Scale Is All You Need*

教科書シリーズ「**T Is All You Need**」（全8巻）の第8巻、最終巻です。
第7巻で作った小さな GPT を出発点に、現代の LLM までの距離を測り、シリーズ全体を回収します。

## この巻の位置づけ

- **入口（前提）**: 第7巻。
- **出口（読了後にできること）**: 「いま君が触っている GPT は、この全体のどこを削ぎ落とし、何を足した形か」を地図として説明できる。Decoder-only・事前学習・fine-tuning・RLHF などを位置づけられる。
- **立ち位置**: シリーズの締め。新しい実装はせず、**回収と位置づけ**に徹する。

## この巻でやらないこと

- 新しいモデルをフルスクラッチで実装する（第7巻で完了）
- 最先端研究を網羅する（各話題は「小さな GPT との差分」に絞る）

> LLM は動きが速く、個々のモデル名・数値はすぐ古くなります。この巻は変わりにくい原理を扱います。固有名や最新の数値が必要なときは一次情報を確認してください。
