# 第1章　この巻の地図

**この章でわかること**

- 元論文の Transformer を、出発点に置くということ
- 現代の LLM を「何を足し、何を削ったか」で読む
- この巻でやらないこと

### 1.1　元論文の Transformer を出発点に置く

シリーズも、この最終巻に、たどり着きました。

第7巻で、あなたは小さな GPT を、自分の手で動かしました。

embedding ＋ Pre-LN の Transformer ブロック ＋ 出力層からなる、Decoder-only の言語モデルです。

それが、文字を生成するところまで、通しました。

ここで、驚くべき事実を、お伝えします。

いま世界で使われている、巨大な LLM（大規模言語モデル）も、その心臓部は、あなたが作ったものと **本質的に同じ** なのです。

embedding があり、Attention があり、残差接続と LayerNorm があり、次の一語を予測する。

その骨格は、あなたの小さな GPT と、変わりません。

だからこの巻では、あなたの小さな GPT を **出発点** に置き、そこから現代の LLM までの距離を、測っていきます。

```text
あなたの小さな GPT（第7巻）  ──？──>  現代の LLM
                            この「？」を埋めるのがこの巻
```

「？」の部分に、何が入るのか。

それを、一つずつ、明らかにしていきます。

### 1.2　現代の LLM を「何を足し、何を削ったか」で読む

現代の LLM は、新しい魔法で、できているわけでは、ありません。

ここを、強調しておきます。

「LLM はブラックボックスで、何か特別な仕組みがある」と思いがちですが、そうではないのです。

元論文の Transformer に対して、

- いくつかを **削り**、
- いくつかを **足し**、
- そして桁違いに **大きく** した、

ものです。

この巻は、その引き算と足し算を、一つずつ、言葉にしていきます。

```text
削ったもの : Encoder（翻訳のための入力側）→ Decoder だけにした
大きくしたもの : パラメータ・データ・計算を桁違いに増やした
足したもの : 事前学習のあとの調整（fine-tuning、指示チューニング、RLHF）など
```

これらを順に見ていけば、「ブラックボックス」だった現代の LLM が、あなたの知っている部品の組み合わせとして、地図の上に、位置づけられます。

未知の何かではなく、既知の部品の、引き算・足し算・拡大。

そう分かれば、LLM が、ぐっと身近になります。

### 1.3　この巻でやらないこと

この巻は、シリーズの **回収と位置づけ** に、徹します。

新しい実装は、しません。

- 新しいモデルを、フルスクラッチで実装する（第7巻で完了。この巻は概念の地図）。
- 最先端研究を、網羅する（横方向の完成主義を避ける）。各話題は「あなたの小さな GPT との差分」に、絞ります。

ここで、大切な注意があります。

LLM の世界は、動きが、とても速いです。

個々のモデル名や、具体的な数値は、すぐ古くなります。

「いちばん大きいモデルは○○で、パラメータ数は△△」といった話は、半年もすれば、変わってしまいます。

だからこの巻は、特定のモデルの最新スペックを追うのでは、ありません。

**変わりにくい原理**――何を削り、何を足し、なぜ大きくすると効くのか――を、扱います。

固有名や最新の数値が必要なときは、最新の一次情報を、別途確認してください。

この巻が与えるのは、「個々の事実」ではなく、「事実を読むための地図」です。

### 1.4　本章のまとめ

- この巻は、第7巻で作った小さな GPT を出発点に、現代の LLM までの距離を測る。
- 現代の LLM は、元論文に対して「Encoder を削り、規模を大きくし、学習後の調整を足した」もの。新しい魔法ではない。
- この巻は回収と位置づけに徹し、新しい実装はしない。最先端の網羅もしない。
- 個々のモデル名・数値（すぐ古くなる）より、変わりにくい原理を扱う。事実を読むための地図を与える。
