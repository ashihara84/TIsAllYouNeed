# 第5章　トークナイザの現実

**この章でわかること**

- BPE などサブワード分割の実際（第4巻3章の回収）
- 語彙サイズと系列長のトレードオフ
- トークン化が、性能・コストに効く理由

### 5.1　現代のトークナイザはサブワード（第4巻3章の回収）

第7巻では、実装を単純にするため、**文字** をトークンにしました。

文字単位は、語彙が小さく、未知語もなく、実装が素直でした。

しかし、現代の LLM は、ほとんどが **サブワード** を、トークンにします（第4巻3章）。

理由は、第4巻で学んだとおり、文字単位と単語単位の、いいとこ取りができるからです。

復習しましょう。

```text
文字単位（第7巻）  : 語彙小・系列長い・未知語なし
単語単位          : 語彙大・系列短い・未知語あり
サブワード（現代）  : バランス型。よく出る語はまるごと、珍しい語は部分に
```

代表的な手法が、**BPE**（Byte Pair Encoding）でした（第4巻3章）。

頻出する隣接ペアを、繰り返し結合して、頻度に応じた粒度の語彙を、作るのでした。

現代では、その発展形（バイト単位の BPE など）が、広く使われます。

バイト単位にすると、何が嬉しいのでしょうか。

どんな文字でも、必ずバイト列に分解できます。

だから、未知語が、原理的になくなります。

絵文字でも、珍しい言語の文字でも、バイトには分解できるからです。

これは、文字単位の「未知語なし」の利点を、サブワードの効率と、両立させたものです。

### 5.2　語彙サイズと系列長のトレードオフ

トークナイザの設計には、語彙サイズと系列長の、トレードオフがあります。

「あちらを立てれば、こちらが立たず」の関係です。

```text
語彙を大きくする  : 1トークンが長い単位を表す → 系列が短くなる
                  → 文脈に多くの内容を詰められるが、embedding 行列と出力層が大きくなる
語彙を小さくする  : 1トークンが短い単位 → 系列が長くなる
                  → モデルは小さくできるが、同じ文章でも処理するトークン数が増える
```

具体的に、考えてみましょう。

語彙を大きくすると、「東京特許許可局」が、1〜2トークンで済むかもしれません。

系列が短くなり、文脈に多くを詰められます。

でも、embedding 行列（第4巻5章）が、語彙サイズ分だけ大きくなります。

語彙を小さくすると、同じ「東京特許許可局」が、もっと多くのトークンに分かれます。

系列が長くなり、同じ文章でも、処理するトークン数が増えます。

ここで、第5巻8章・第6巻8章で見たことが、効きます。

Self-Attention の計算量は、系列長の2乗に効くのでした。

だから、系列が長くなると、計算コストが、効いてきます。

語彙サイズは、このバランスを取る、重要な設計判断なのです。

### 5.3　トークン化が性能・コストに効く理由

トークナイザは、地味です。

でも、性能とコストに、直接効きます。

**コスト。**

LLM の利用料金や計算量は、しばしば「トークン数」で、測られます。

同じ文章でも、トークナイザによって、何トークンになるかが、変わります。

効率のよい分割は、そのまま、コスト削減になります。

「この文章は、このトークナイザだと100トークン、あのトークナイザだと150トークン」。

そういう違いが、料金や計算量に、直結するのです。

**性能。**

分割の仕方は、モデルの扱いやすさに、影響します。

例を挙げましょう。

数字を、1桁ずつに分けるか、まとめるかで、計算（算術）の扱いやすさが、変わることが、知られています。

「123」を「1」「2」「3」と分けるか、「123」とまとめるかで、足し算のしやすさが、変わるのです。

言語によっても、効率のよい分割は、異なります。

英語向けに作った語彙は、他言語だと、トークン数が増えがち、という問題もあります。

```text
トークン化は、モデルの「入口」。
ここでの粒度の選び方が、計算量・コスト・扱いやすさに、波及する。
```

第7巻で文字単位にしたのは、学習用の単純化でした。

本物では、このトークナイザの設計が、一つの重要な工学に、なっている。

そう押さえておけば、十分です。

詳細な手法や、各モデルの語彙は、更新が速いので、必要なら一次情報を、確認してください。

### 5.4　本章のまとめ

- 現代の LLM はサブワード（BPE やその発展形）をトークンにする。第7巻の文字単位は、学習用の単純化。
- バイト単位の BPE は、どんな文字もバイト列に分解でき、未知語を原理的になくせる。
- 語彙サイズと系列長はトレードオフ。系列長は Self-Attention の2乗コストに効く（第6巻8章）。
- トークン化は性能とコスト（トークン課金・計算量・扱いやすさ）に直結する、重要な設計。
