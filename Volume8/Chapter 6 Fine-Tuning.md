# 第6章　fine-tuning

**この章でわかること**

- 事前学習済みモデルを、下流タスクに合わせる
- 全パラメータ更新と、軽量手法（LoRA などの直感）
- 第1巻の「学習＝損失を下げる」が、そのまま効く

### 6.1　事前学習済みモデルを下流タスクに合わせる

事前学習を終えたベースモデル（第4章）は、言語を広く学んでいます。

しかし、特定の用途に、ぴったり合っているとは、限りません。

たとえば、「広く言語を知っている」ベースモデルを、「医療文書の要約」という、特定の仕事に、使いたいとします。

そのままでも、ある程度はできますが、その仕事に特化させれば、もっとうまくできます。

そこで、目的のタスクのデータで、追加学習し、モデルを調整します。

これが **fine-tuning**（ファインチューニング、微調整）です。

```text
事前学習（広く言語を学ぶ）
  ↓
fine-tuning（特定タスク・特定の振る舞いに合わせる）
```

ポイントは、ゼロから学習し直すのでは、ない、ということです。

すでに賢いモデルを、「少し調整する」だけ。

だから、必要なデータも、計算も、事前学習より、ずっと少なくて済みます。

事前学習は、何ヶ月もかかる、巨大な作業でした。

fine-tuning は、それに比べれば、ずっと手軽です。

これが、「事前学習＋fine-tuning」という2段構えの、強みです。

一度、巨大な事前学習をしておけば、あとは、いろいろなタスクに、少しの追加学習で、対応できるのです。

### 6.2　第1巻の「学習＝損失を下げる」がそのまま効く

fine-tuning も、学習の中身は、このシリーズで学んだこと、そのものです。

特別な仕組みは、ありません。

タスクのデータで、損失を計算し、勾配を流し、パラメータを更新する。

第1巻から繰り返してきた、あの営みです。

```text
fine-tuning の中身:
  タスクのデータ → forward → loss → backward → step
  （第3巻7章・第7巻11章の学習ループと同じ骨格）
```

第3巻7章・第7巻11章で書いた、あの学習ループと、同じ骨格です。

新しい原理は、ありません。

違うのは、一点だけ。

「ランダムな初期値から始める」のでは、なく、「事前学習済みの賢い状態から始める」ことです。

出発点が良いので、少しの学習で、目的に近づけます。

山登りにたとえれば、こうです。

ゼロからの学習は、ふもとから登る。

fine-tuning は、八合目から登る。

八合目から始めれば、頂上は、すぐそこです。

### 6.3　全パラメータ更新と軽量手法（LoRA などの直感）

fine-tuning には、大きく2つの、やり方があります。

**全パラメータ更新（フル fine-tuning）。**

モデルの全パラメータを、更新します。

効果は高いですが、巨大なモデルだと、更新にも保存にも、莫大なコストが、かかります。

そして、タスクごとに、モデル全体のコピーが、必要になります。

10個のタスクがあれば、巨大なモデルのコピーが、10個。

これは、現実的では、ありません。

**軽量手法（パラメータ効率の良い fine-tuning）。**

モデル本体は、ほぼ凍結し、ごく少数の追加パラメータだけを、学習します。

代表が **LoRA** です。

直感としては、こうです。

「元の重み行列は、そのままに、小さな『差分』だけを、学習して足す」。

```text
フル fine-tuning : 全パラメータを更新（高コスト・高効果）
LoRA など        : 本体は凍結し、小さな差分だけ学習（低コスト・実用的）
```

なぜ、これで済むのでしょうか。

直感的には、「賢いモデルを、特定タスクに合わせる調整は、そんなに大きな変更ではない」からです。

本体はそのままで、小さな差分を足すだけで、十分なことが多いのです。

LoRA のような軽量手法は、

- 少ない計算とメモリで fine-tuning でき、
- タスクごとに、小さな差分だけ保存すればよい、

ので、現代では、広く使われます。

10個のタスクなら、巨大な本体は1つ、小さな差分が10個。

これなら、現実的です。

「巨大なモデルを、安く・たくさん・用途別に調整する」ための工夫だと、押さえておけば、十分です。

### 6.4　本章のまとめ

- fine-tuning は、事前学習済みモデルを、目的のタスクや振る舞いに合わせる、追加学習。
- 中身は「forward → loss → backward → step」で、第3巻・第7巻の学習ループと同じ。出発点が賢いだけ（八合目から登る）。
- 全パラメータ更新は高効果・高コスト。LoRA などの軽量手法は、小さな差分だけ学習して低コストに。
- 「事前学習＋fine-tuning」の2段構えが、少ないデータ・計算で用途に合わせられる強み。
