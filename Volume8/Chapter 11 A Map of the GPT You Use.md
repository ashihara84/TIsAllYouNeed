# 第11章　いま君が触っている GPT の地図

**この章でわかること**

- 入力から出力までを、全部追えるか（総点検）
- どの部品が、1〜7巻のどこに対応するか
- ブラックボックスだったものが、地図になった

### 11.1　入力から出力までを全部追う

シリーズの締めくくりに、総点検をしましょう。

いま私たちが日常的に使っている、対話 AI（GPT 系）が、あなたの入力に応答するまでを、最初から最後まで、追ってみます。

すべて、このシリーズで学んだことで、説明できます。

```text
1. あなたが文章を入力する
2. トークナイザがサブワードに分割し、ID 列にする（第8巻5章 / 第4巻3-4章）
3. embedding でベクトルにし、位置の情報を足す（第4巻5章 / 第5巻8章 / 第7巻7章）
4. causal mask 付き Multi-Head Attention と FFN のブロックを、
   何段も通る（第5巻 / 第7巻8-9章）。各ブロックは Pre-LN で残差に包まれている（第3巻）
5. 出力層が、次トークンの確率分布（ロジット）を出す（第4巻7章 / 第7巻10章）
6. temperature・top-k/top-p でサンプリングし、次トークンを選ぶ（第8巻9章 / 第7巻12章）
7. それを末尾に足して、また 3 へ。KV キャッシュで高速化（第8巻9章）
8. 終了条件まで繰り返し、応答が生成される
```

この8ステップを、よく見てください。

未知の魔法は、1つも、ありません。

すべて、あなたが理解し、その多くを、自分で実装した部品です。

トークン化も、embedding も、Attention も、サンプリングも。

あなたが、第3巻から第7巻まで、自分の手で、通ってきたものです。

### 11.2　どの部品が1〜7巻のどこに対応するか

応答を支える土台を、シリーズ全体の地図として、並べましょう。

```text
機械学習の枠組み（損失・勾配降下・汎化）      → 第1巻
数学（ベクトル・内積・softmax・微分）         → 第2巻
ニューラルネット・残差接続・LayerNorm         → 第3巻
トークン化・embedding・言語モデル            → 第4巻
Attention・Q/K/V・Multi-Head・位置・FFN      → 第5巻
論文の設計と理由                            → 第6巻
統合・学習・生成（小さな GPT）               → 第7巻
Decoder-only・事前学習・調整・推論の工夫      → 第8巻（本書）
```

現代の LLM は、この積み重ねの上に、「規模」と「学習後の調整」を、足したものです。

あなたは、その土台の、ほぼすべてを、自分の手で、通り抜けてきました。

第1巻の機械学習の直感から、第7巻の動く GPT まで。

一段ずつ、登ってきたのです。

### 11.3　ブラックボックスだったものが地図になった

このシリーズを始める前、「GPT」は、おそらく、こういうものでした。

入れると答えが出てくる、中の見えない、箱。

なぜそう答えるのか、中で何が起きているのか、分からない。

いまは、違います。

```text
入力 → トークン化 → embedding+位置 → [Attention+FFN]×N → 出力分布 → サンプリング → …
```

この一行を、あなたはもう、各段で「何が・なぜ・どう」起きているかまで、説明できます。

「ここでトークンに分けて」「ここでベクトルにして」「ここで文脈を混ぜて」「ここで次の語を選ぶ」。

ブラックボックスが、隅々まで歩ける、地図になったのです。

これこそ、このシリーズが目指した、到達点でした。

最初に立てた目標――「Transformer を自分で実装できるようになる」――の、その先にある景色です。

もちろん、現代の LLM のすべてが、この地図に収まるわけでは、ありません。

地図の外にも、広大な領域が、広がっています。

- 巨大スケール特有の現象、
- 安全性の工夫、
- マルチモーダル（画像や音声も扱う）への拡張、

など。

しかし、その広大な領域も、この地図を足場にして、探検できます。

土台を持っているからこそ、新しいものを「既知の何かとの差分」として、理解できるのです。

「これは、第5巻の Attention を、こう変えたものか」。

「これは、第8巻の fine-tuning の、発展形か」。

そう読み解けるのは、土台を、自分のものにしたからです。

### 11.4　本章のまとめ

- 現代の GPT が、あなたの入力に応答するまでの8ステップは、すべてこのシリーズで学んだ部品で説明できる。
- 機械学習・数学・ニューラルネット・言語・Attention・論文・実装・LLM 化と、土台はすべて手の内にある。
- ブラックボックスだった GPT が、隅々まで歩ける地図になった。これが到達点。
- 地図の外（巨大スケール特有の現象、安全性、マルチモーダル等）も、この土台を足場に、「既知との差分」として探検できる。
