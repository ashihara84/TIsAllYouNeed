# 第2章　元論文から何が変わったか

**この章でわかること**

- Encoder–Decoder から Decoder-only へ
- 規模（パラメータ・データ・計算）の桁が変わった
- 学習の目的は同じ（次トークン予測）であることの確認

### 2.1　全体像：3つの変化

第6巻で読んだ元論文の Transformer と、現代の LLM の違いは、大きく3つに、まとめられます。

```text
1. 構造：Encoder–Decoder → Decoder-only（GPT 系）
2. 規模：パラメータ・データ・計算が、桁違いに増えた
3. 学習後：事前学習だけでなく、調整（fine-tuning, 指示, RLHF）を重ねる
```

この章では、1と2を概観します。

3は、次章以降で、詳しく扱います。

そして、これらの変化の **底にあるもの** は、変わっていません。

それが「次トークン予測」だ、という確認が、この章の締めです。

何が変わって、何が変わらないか。

それを、はっきりさせましょう。

### 2.2　Encoder–Decoder から Decoder-only へ

元論文は、翻訳のためのモデルで、

- 入力文を読む Encoder と、
- 出力文を生成する Decoder、

の両方を、持っていました（第6巻3〜4章）。

英語を読む側（Encoder）と、日本語を作る側（Decoder）が、別々にあったのです。

現代の主流である GPT 系は、**Decoder だけ** を、使います。

あなたが第7巻で作ったのも、まさに、この Decoder-only でした。

なぜ Decoder だけで足りるのか、という核心は、次章で扱いますが、ここでは、こう押さえます。

「翻訳のための入力側（Encoder）を削ぎ落とし、ひたすら次トークンを予測する形に、絞った」。

```text
元論文     : Encoder（入力理解）＋ Decoder（生成）
GPT 系     : Decoder のみ（次トークン予測に特化）
```

2つあったものを、1つに絞った。

それが、1つ目の変化です。

### 2.3　規模の桁が変わった

2つ目の、そして見た目にいちばん大きい変化が、規模です。

元論文のモデルは、当時としては大きくても、現代の LLM と比べれば、小さなものでした。

現代の LLM は、

- パラメータ数も、
- 学習データ量も、
- 計算量も、

いずれも、桁違いに、増えています。

イメージで言うと、こうです。

```text
              パラメータ        学習データ         計算
元論文        〜億のオーダー     翻訳コーパス       当時の大型実験
現代の LLM    桁違いに大きい     膨大なテキスト      桁違いに大きい
```

具体的な数値は、モデルごとに違い、しかも年々、更新されます。

だから「いくつ」より、「桁違いに大きくした」という事実と、「なぜ大きくすると賢くなるのか」（第4章のスケールの話）を、押さえることが、大切です。

ここで、あなたの第7巻の経験が、効きます。

あなたが第7巻で作った小さな GPT も、構造を変えずに、この規模を上げていけば、原理的には、現代の LLM に、連続的につながります。

違いは、質ではなく、量なのです。

「まったく別物」ではなく、「同じものの、巨大版」。

そう捉えてください。

### 2.4　学習の目的は同じ（次トークン予測）

ここが、この章で、いちばん強調したい点です。

構造を削り、規模を上げても、**学習の目的そのものは、第4巻7章で学んだ「次トークン予測」のまま** です。

並べてみましょう。

```text
元論文の Decoder       : 次のトークンを予測する
あなたの小さな GPT     : 次の文字を予測する（第7巻）
現代の巨大な LLM       : 次のトークンを予測する
→ 目的は同じ
```

どれも、「これまでの列を見て、次の一語を当てる」。

それだけです。

膨大なテキストで「ひたすら次の一語を当てる」を続けるうちに、

- 文法も、
- 知識も、
- 推論のような振る舞いも、

副産物として、身についていきます。

第4巻7章で「次の一語を当てるだけで、いろいろ身につく」と述べた、その直感が、巨大なスケールで現実になったのが、現代の LLM です。

だから、あなたは、現代の LLM の学習目的を、すでに知っています。

新しい原理では、ありません。

知っている原理を、巨大にしただけ、なのです。

「次の一語を当てる」という、あなたが第7巻で実装したあの目的が、世界最大の LLM でも、同じように使われている。

そう思うと、現代の LLM が、ぐっと身近に感じられるはずです。

### 2.5　本章のまとめ

- 元論文から現代の LLM への変化は、(1) Decoder-only 化、(2) 規模の桁違いの増大、(3) 学習後の調整の追加。
- GPT 系は Encoder を削り、Decoder だけで次トークン予測に特化した（第7巻で作った形）。
- 規模は桁違いに大きくなったが、具体的な数値より「大きくした」事実と「なぜ効くか」が大切。違いは質でなく量。
- 学習の目的は、元論文も現代も「次トークン予測」で同じ。知っている原理を、巨大にしただけ。
