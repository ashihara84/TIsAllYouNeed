# 第12章　まとめ：論文の一行を謎にしないために

**この章でわかること**

- この巻で書けるようになったもの（部品表）
- 残差接続と LayerNorm が、この先どこで効くか
- 次の巻（言語をベクトルにする）への橋

### 12.1　この巻で書けるようになったもの（部品表）

第3巻を通して、たくさんのものを、自分の手で書けるようになりました。

チェックリストの形で、振り返りましょう。

```text
□ 1個のニューロン（線形変換 W・x + b）              … 第2章
□ 活性化関数（ReLU など）を挟んだ多層 MLP           … 第2〜4章
□ バッチをまとめて流す順伝播（shape を追える）        … 第3章
□ softmax と cross entropy をつないだ出力層と損失     … 第5章
□ loss.backward() による逆伝播（autograd）          … 第6章
□ forward → loss → backward → step の学習ループ      … 第7章
□ XOR を解く MLP を、最後まで学習させ切る            … 第8章
□ 残差接続 x + f(x)                                  … 第9章
□ LayerNorm（gamma, beta つき）                      … 第10章
□ LayerNorm(x + Sublayer(x)) のブロックの骨格        … 第10章
□ 学習を安定させる小技（初期化・Dropout・クリッピング）… 第11章
```

これだけのものを、コードで書けるようになったのです。

第1巻では、これらを「読んで腑に落ちる」だけでした。

いまは、手が動きます。

これらは、第5巻で Transformer の部品を作り、第7巻でそれらを統合して動かすときの、土台の部品です。

### 12.2　残差接続と LayerNorm はこの先どこで効くか

この巻でいちばん強調したのは、残差接続（第9章）と LayerNorm（第10章）でした。

改めて、これらが、この先のどこで効くのかを、確認します。

```text
第5巻：
  Attention や FFN という「中身（Sublayer）」を作る。
  それを x + Sublayer(x) で包み、LayerNorm で整える。
  → 残差接続と LayerNorm が、ここで使われる。

第6巻：
  論文の LayerNorm(x + Sublayer(x)) を読む。
  → 「ああ、第3巻で書いた、あの骨格だ」と読める。

第7巻：
  ブロックを何段も積んで、文字レベル言語モデルとして動かす。
  → 残差接続のおかげで、深く積んでも学習できる。
```

第1章で「論文の `LayerNorm(x + Sublayer(x))` を謎にしないために」と言いました。

いまや、この式の `x +`（残差接続）も、`LayerNorm(...)`（正規化）も、自分で実装したものです。

もう、謎ではありません。

残るは、中身の `Sublayer`、つまり Attention だけ。

それが、次の2巻（第4巻・第5巻）のテーマです。

### 12.3　次の巻（言語をベクトルにする）への橋

ここまで、入力はずっと「数のベクトル」でした。

XOR の `[0, 1]` のように、すでに数になっているものを扱ってきました。

しかし、思い出してください。

Transformer が相手にするのは、言語です。

文字や単語といった、そのままでは数でないものを、どうやってニューラルネットに入れるのか。

「犬」という単語を、どんなベクトルにすれば、意味を扱えるのか。

「犬」と「猫」が似ている、という関係を、どう表せばよいのか。

これらは、まだ何も解決していません。

それが、次の第4巻「言語をベクトルにする／系列を扱う」のテーマです。

第4巻では、

- tokenization（トークン化：文章をトークンに切る）、
- embedding（埋め込み：トークンを意味の載るベクトルにする）、
- 言語モデル（次トークン予測）、

を学びます。

さらに、「RNN は何が辛くて、Attention が何を足したのか」という、Transformer 誕生の動機までを、語れるようにします。

そこまで来れば、第5巻で、いよいよ Attention の部品を、この巻で身につけた手つきで、作り始められます。

この巻で「手が動く」ようになったあなたなら、それができます。

### 12.4　本章のまとめ

- この巻で、線形変換・活性化・損失・逆伝播・学習ループ・残差接続・LayerNorm を、自分で書けるようになった。
- 残差接続と LayerNorm は、第5巻のブロック作り、第6巻の論文読解、第7巻の統合で効く。
- 論文の `LayerNorm(x + Sublayer(x))` のうち、残る謎は中身の `Sublayer`（＝Attention）だけ。
- 次の第4巻では、言語をベクトルにする方法と、Attention 誕生の動機を学ぶ。
