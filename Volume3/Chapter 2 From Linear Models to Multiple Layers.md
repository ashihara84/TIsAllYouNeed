# 第2章　線形モデルから多層へ

**この章でわかること**

- 1個のニューロンを式で書くとどうなるか
- 線形モデルだけでは解けない問題が、具体的にどういうものか
- 層を重ねるとは、何をしていることなのか
- なぜ層の間に「活性化関数」が必要なのか
- 多層パーセプトロン（MLP）の全体像

### 2.1　1個のニューロンを式で書く

第1巻で、モデルは「入力を受け取り、出力を返す関数」だと学びました。

そのなかで、いちばん単純なモデルが、直線（線形モデル）でした。

入力 `x` が1つの数だけのとき、線形モデルは次のように書けます。

```text
y = w * x + b
```

ここで `w` は重み（weight）、`b` はバイアス（bias）です。

これらが、学習で決まるパラメータでした（第1巻3章）。

たとえば、`w = 2`、`b = 1` だとしましょう。

このとき、入力 `x = 3` を入れると、出力はこうなります。

```text
y = 2 * 3 + 1 = 7
```

入力 `x = 5` なら、

```text
y = 2 * 5 + 1 = 11
```

このように、`w` と `b` が決まれば、入力から出力が1つに決まります。

さて、入力が1つの数ではなく、複数あるときはどうなるでしょうか。

たとえば、家の価格を「広さ」と「駅からの距離」の2つから予測したいとします。

このときは、入力が2つ、重みも2つになります。

```text
y = w1 * x1 + w2 * x2 + b
```

`x1` が広さ、`x2` が駅からの距離、というわけです。

入力が3つ、4つと増えても、同じです。

```text
y = w1*x1 + w2*x2 + w3*x3 + b
```

これは、第2巻で学んだ内積を使うと、すっきり書けます。

入力をまとめたベクトル `x` と、重みをまとめたベクトル `w` の内積です。

```text
y = w・x + b
```

第2巻4章で「内積は、対応する要素を掛けて、全部足す」と学びました。

まさにそれを使っています。

これが「1個のニューロン」の正体です。

やっていることは、たった2つです。

1. 入力ベクトルと重みベクトルの内積を取る。
2. そこにバイアスを足す。

これだけで、1つの数を返します。

PyTorch では、この計算を `nn.Linear` がまとめてやってくれます。

```python
import torch
import torch.nn as nn

# 入力3次元 -> 出力1次元 のニューロン
neuron = nn.Linear(3, 1)

x = torch.tensor([1.0, 2.0, 3.0])
y = neuron(x)

print(y)        # 1つの数（に近いテンソル）
print(y.shape)  # torch.Size([1])
```

`nn.Linear(3, 1)` の中には、重み `w`（3個）とバイアス `b`（1個）が入っています。

これらの値は、最初はランダムです。

学習を通じて、これらが「良い値」へと調整されていきます。

### 2.2　線形モデルだけでは解けない例

ニューロン1個、つまり線形モデルには、はっきりとした限界があります。

それは、「直線（平面）でしか境界を引けない」ことです。

これを、有名な例で確かめましょう。

XOR（排他的論理和）という問題です。

次の4つの入力を、2つのグループ（A と B）に分けたいとします。

```text
入力 (0, 0) → グループ A
入力 (1, 1) → グループ A
入力 (0, 1) → グループ B
入力 (1, 0) → グループ B
```

ルールを言葉にすると、こうです。

「2つの入力が同じなら A、違うなら B」。

これを平面に置いてみましょう。

横軸を `x1`、縦軸を `x2` とします。

```text
x2
 1 |  B(0,1)      A(1,1)
   |
 0 |  A(0,0)      B(1,0)
   +----------------------
      0            1     x1
```

A は左下と右上、B は左上と右下にあります。

つまり A と B が「斜め向かい」に配置されています。

ここで、1本の直線を引いて、A と B を分けられるか試してみてください。

どう引いても、できません。

たとえば縦に1本引けば、左側に A(0,0) と B(0,1)、右側に B(1,0) と A(1,1) が来ます。

左側にも右側にも、A と B が混ざってしまいます。

横に引いても、斜めに引いても、同じです。

1本の直線では、この4点を A と B にきれいに分けることはできません。

これが、線形モデルの限界です。

第1巻12章で「線形モデルの限界」「非線形性が必要になる理由」として直感的に触れたのが、まさにこの XOR でした。

直線1本では足りない。

では、どうすればよいのでしょうか。

### 2.3　層を重ねるとは何か

答えは、「ニューロンを並べて、その出力を、さらに次のニューロンの入力にする」ことです。

これが **層を重ねる** ということです。

イメージを言葉にすると、こうなります。

1段目（隠れ層）で、入力を「別の表現」に変換する。

2段目（出力層）で、その表現から答えを出す。

```text
入力 x
  ↓ 1段目（隠れ層）：複数のニューロン
隠れ表現 h
  ↓ 2段目（出力層）
出力 y
```

ところが、ここで一つ、とても大切な落とし穴があります。

**線形変換を2回重ねても、全体としては、また1つの線形変換にしかならない**のです。

これを確かめてみましょう。

1段目を `h = W1・x`、2段目を `y = W2・h` とします（バイアスは省略）。

`h` を `y` の式に代入すると、

```text
y = W2・(W1・x)
```

第2巻5章で学んだ行列のかけ算の性質から、`W2・W1` は1つの行列にまとまります。

それを `W` と呼べば、

```text
y = (W2・W1)・x = W・x
```

結局、入力に1つの行列を掛けただけ、つまり1つの線形変換になってしまいました。

これでは、層を2段に重ねた意味がありません。

XOR は、相変わらず解けないままです。

困りました。

層を重ねたいのに、ただ重ねるだけでは、1段のときと変わらない。

この壁を破るのが、次の節の「活性化関数」です。

### 2.4　活性化関数で「折り曲げる」

前の節の問題は、「線形変換 ＋ 線形変換 ＝ 線形変換」だったことでした。

そこで、層と層の間に、**非線形な関数** を挟みます。

これを活性化関数と呼びます。

```text
h = 活性化(W1・x + b1)   ← ここに非線形性を入れる
y = W2・h + b2
```

活性化関数を挟むと、もう `W2・W1` のように1つにまとめることはできません。

なぜなら、間に「まっすぐでない」操作が入るからです。

この「まとめられなさ」こそが、複雑な境界を表現する力の源になります。

直感的なイメージを持ちましょう。

線形変換は、平面を「まっすぐ引き伸ばしたり、回したり」する操作です。

しかし、まっすぐな操作だけでは、まっすぐな境界しか作れません。

活性化関数は、その途中で平面を「折り曲げる」操作です。

折り曲げを何度か入れると、まっすぐではない、複雑な境界が作れるようになります。

XOR のような「斜め向かい」も、折り曲げを使えば分けられます。

活性化関数の具体的な中身（ReLU など）は、次の第4章でじっくり扱います。

ここでは、「層の間に非線形を挟むと、はじめて複雑な境界が作れる」という事実をつかんでください。

### 2.5　隠れ層という考え方

入力層と出力層の間にある層を、**隠れ層**（hidden layer）と呼びます。

「隠れ」という名前は、入力でも最終出力でもない、途中の表現だからです。

外から直接は見えない、中間の段、というわけです。

隠れ層の役割は、入力を「次の判断に使いやすい表現」に変換することです。

これは、第1巻10章で学んだ「特徴量・表現」の話と地続きです。

第1巻では、人間が特徴量を設計する話をしました。

ニューラルネットでは、その特徴量にあたる「有用な表現」を、隠れ層が学習を通じて自動で見つけていきます。

人間が「広さと駅距離を掛け合わせた特徴が効くはずだ」と手で設計する代わりに、隠れ層がそういう組み合わせを自分で見つける、というイメージです。

隠れ層には、設計者が決める2つの大きさがあります。

**幅**：1つの隠れ層に、ニューロンを何個置くか。

**深さ**：隠れ層を、何段重ねるか。

これらは、学習で決まるパラメータではなく、人間が決める **ハイパーパラメータ** です（第1巻3章）。

幅や深さを増やすほど、モデルの表現力は上がります。

しかし、増やしすぎると、過学習しやすくもなります（第1巻7章）。

このバランスを取るのも、設計の一部です。

### 2.6　多層パーセプトロン（MLP）の全体像

入力層・隠れ層・出力層を、線形変換と活性化関数で順につないだもの。

これを **多層パーセプトロン**（Multi-Layer Perceptron, MLP）と呼びます。

この巻で最初に自分で書くのが、この MLP です。

隠れ層が1つの場合、全体を式で書くと、こうなります。

```text
h = 活性化(W1・x + b1)   ← 入力を隠れ表現へ
y = W2・h + b2           ← 隠れ表現を出力へ
```

図にすると、次の流れです。

```mermaid
flowchart LR
    X["入力 x"] --> L1["線形 W1, b1"]
    L1 --> A["活性化"]
    A --> L2["線形 W2, b2"]
    L2 --> Y["出力 y"]
```

左から右へ、入力が層を通って、出力になります。

これが順伝播（次章）の流れです。

PyTorch では、この全体を、数行で書けます。

```python
import torch
import torch.nn as nn

mlp = nn.Sequential(
    nn.Linear(2, 8),   # 入力2 -> 隠れ8
    nn.ReLU(),         # 活性化（非線形）
    nn.Linear(8, 1),   # 隠れ8 -> 出力1
)

x = torch.tensor([0.0, 1.0])
print(mlp(x))
```

`nn.Sequential` は、「中身を順番に通す」という意味です。

ここでは、入力2次元を、

1. `nn.Linear(2, 8)` で 8次元の隠れ表現にし、
2. `nn.ReLU()` で非線形に折り曲げ、
3. `nn.Linear(8, 1)` で 1次元の出力にする、

という流れを表しています。

途中の `8` が、隠れ層の幅です。

これを `16` や `32` に変えれば、表現力の高いモデルになります。

これが、XOR のような「直線では解けない問題」も表現できる、最小のニューラルネットワークです。

次章からは、この MLP の中身を、一つずつ自分の手で確かめていきます。

まず次の第3章で、順伝播を行列の計算として書きます。

### 2.7　本章のまとめ

- 1個のニューロンは `y = w・x + b`。入力との内積に、バイアスを足すだけ。
- 線形モデル（直線）だけでは、XOR のような「斜め向かい」の問題は解けない。
- 線形変換を重ねるだけでは、また1つの線形変換にしかならない（`W2・W1` は1つの行列）。
- だから、層の間に **活性化関数（非線形）** を挟む。これが平面を「折り曲げ」、複雑な境界を作る。
- 入力と出力の間の層を隠れ層と呼び、有用な表現を学習で自動的に見つける。幅と深さはハイパーパラメータ。
- 線形変換と活性化を順につないだものが MLP。この巻で最初に自分で書くモデルである。
