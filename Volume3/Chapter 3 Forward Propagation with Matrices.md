# 第3章　順伝播を行列で書く

**この章でわかること**

- 1つのニューロンの計算を、層全体の行列計算へ拡張する方法
- 重み行列とバイアスの shape の読み方
- 順伝播とは、具体的に何をしていることなのか
- 複数の入力（バッチ）を、まとめて流す方法
- 順伝播を PyTorch で確認する

### 3.1　入力ベクトルから出力ベクトルへ

前章で、1個のニューロンを `y = w・x + b` と書きました。

これは、入力ベクトルから「1つの数」を作る計算でした。

しかし、隠れ層には、こうしたニューロンが複数並んでいます。

たとえば、隠れ層に8個のニューロンがあるとします。

このとき、各ニューロンが、それぞれ自分の重みベクトルを持っています。

つまり、重みベクトルが8本ある、ということです。

```text
ニューロン0 の重み： w(0) = [w(0,1), w(0,2), w(0,3)]
ニューロン1 の重み： w(1) = [w(1,1), w(1,2), w(1,3)]
...
ニューロン7 の重み： w(7) = [w(7,1), w(7,2), w(7,3)]
```

この8本の重みベクトルを、縦に積み重ねると、1つの行列になります。

これが **重み行列** です。

第2巻5章・6章で学んだ「行列は、ベクトルを別のベクトルへ変換する」という考えが、ここでそのまま効きます。

shape を整理しておきましょう。

```text
入力 x        : 長さ 3 のベクトル
重み行列 W1   : 8 行 3 列の行列   （出力8 × 入力3）
バイアス b1   : 長さ 8 のベクトル
隠れ表現 h    : 長さ 8 のベクトル
```

計算は、行列とベクトルの掛け算に、バイアスを足すだけです。

```text
h = W1・x + b1
```

shape を追ってみましょう。

`W1・x` は、`[8, 3]` の行列と、長さ3のベクトルの積です。

第2巻5章で学んだルールから、`[8, 3] × [3]` の結果は、長さ8のベクトルになります。

```text
[8, 3] と [3] の積  →  [8]
```

そこに、長さ8のバイアス `b1` を足します。

長さ8どうしなので、ちょうど足せます。

結果は、長さ8の隠れ表現 `h` です。

このように、shape が合っていることを、いつも確認する習慣をつけてください。

shape が合わなければ、計算は成り立ちません。

### 3.2　重み行列とバイアス（第2巻の線形変換の回収）

第2巻6章で、`Wx + b` を「入力ベクトルを別の表現へ変換する操作」として学びました。

ニューラルネットの1層は、まさにこの `Wx + b` に、活性化を加えたものです。

つまり、第2巻で学んだ線形変換が、ニューラルネットの土台になっているのです。

PyTorch の `nn.Linear(in_features, out_features)` は、この `W` と `b` を内部に持っています。

実際に、その中身を覗いてみましょう。

```python
import torch
import torch.nn as nn

layer = nn.Linear(3, 8)   # 入力3 -> 出力8

print(layer.weight.shape)  # torch.Size([8, 3])  ← W は [出力, 入力]
print(layer.bias.shape)    # torch.Size([8])     ← b は [出力]
```

ここで、重要な注意があります。

`weight` の shape が `[8, 3]`、つまり `[出力, 入力]` の順になっています。

「入力3、出力8」と指定したのに、shape は `[8, 3]` です。

出力が先、入力が後、という順番です。

これは PyTorch の規約（決まりごと）です。

内部では `x @ W.T + b` のように、転置を使って計算され、結果として長さ8のベクトルが得られます。

最初は戸惑うかもしれませんが、「`weight` は `[出力, 入力]` の順」と覚えてしまえば大丈夫です。

### 3.3　1層の順伝播を実装する

実際に、1層分の順伝播を動かしてみましょう。

```python
import torch
import torch.nn as nn

layer = nn.Linear(3, 8)

x = torch.tensor([1.0, 2.0, 3.0])   # 長さ3
h = layer(x)                        # 長さ8

print(h.shape)   # torch.Size([8])
```

`layer(x)` を呼ぶと、内部で `x @ W.T + b` が計算されます。

これが「1層の順伝播」です。

**順伝播（forward propagation）** とは、入力を層に通して、出力まで前向きに計算していくこと。

ただ、それだけのことです。

難しい言葉に聞こえますが、やっていることは「入力を、層の式に通して、出力を得る」だけです。

「前向き（forward）」というのは、入力から出力へ、という向きを表しています。

後の章で出てくる「逆伝播（backward）」は、その逆向き、出力から入力へ、です。

### 3.4　複数層をつなぐ

隠れ層を通したあとは、活性化関数を挟み、次の層へ渡します。

2層の MLP を、層を明示的に並べて書いてみましょう。

```python
import torch
import torch.nn as nn

l1 = nn.Linear(3, 8)
act = nn.ReLU()
l2 = nn.Linear(8, 2)

x = torch.tensor([1.0, 2.0, 3.0])

h = l1(x)     # [3] -> [8]
h = act(h)    # [8] -> [8]（非線形に折り曲げる）
y = l2(h)     # [8] -> [2]

print(y.shape)  # torch.Size([2])
```

ここで、shape の変化を追ってみてください。

```text
入力 x : [3]
 ↓ l1（線形）
       : [8]
 ↓ act（活性化）
       : [8]
 ↓ l2（線形）
出力 y : [2]
```

入力 `[3]` → 隠れ `[8]` → 出力 `[2]` と、層ごとに次元（数の個数）が変わっていきます。

順伝播とは、この「shape を変えながら、前へ流す」操作の連続なのです。

活性化（`act`）のところだけ、shape が `[8]` のまま変わっていません。

活性化は、各要素を個別に折り曲げるだけで、数の個数は変えないからです。

### 3.5　バッチをまとめて流す（shape を追う）

ここまでは、データを1件だけ流してきました。

しかし、実際の学習では、データを1件ずつではなく、まとめて流します。

これを **バッチ** と呼びます。

なぜまとめるのでしょうか。

理由は2つあります。

1つ目は、効率です。

1件ずつ計算するより、まとめて計算するほうが、コンピュータにとって速いのです。

2つ目は、学習の安定です（詳しくは第1巻5章のミニバッチ学習）。

入力を `[batch_size, in_features]` の行列にすると、層を通しても、先頭の `batch_size` はそのまま保たれます。

実際に確かめてみましょう。

```python
import torch
import torch.nn as nn

l1 = nn.Linear(3, 8)
l2 = nn.Linear(8, 2)
act = nn.ReLU()

# 4件のデータをまとめて流す
x = torch.randn(4, 3)    # [batch=4, in=3]

h = act(l1(x))           # [4, 8]
y = l2(h)                # [4, 2]

print(x.shape, "->", h.shape, "->", y.shape)
# torch.Size([4, 3]) -> torch.Size([4, 8]) -> torch.Size([4, 2])
```

shape の変化を、丁寧に追いましょう。

```text
入力 x : [4, 3]   （4件、各3次元）
 ↓
       : [4, 8]   （4件、各8次元）
 ↓
出力 y : [4, 2]   （4件、各2次元）
```

先頭の `4`（バッチ）は、最初から最後まで変わっていません。

変わっているのは、各データの次元（`3 → 8 → 2`）だけです。

これは、「4件のデータが、それぞれ独立に、同じ計算を受けている」ことを意味します。

データ0 もデータ1 も、同じ重み行列で変換されます。

ただ、4件まとめて計算しているだけなのです。

この「shape を見れば、何件のデータが、何次元の表現を通っているかが読める」という感覚。

これは、第5巻・第7巻で Attention の shape を追うときに、そのまま強力な武器になります。

たとえば、第5巻で `[batch, 系列長, d_model]` という3次元の shape が出てきます。

そのとき、「先頭がバッチ、最後が表現の次元」という、いまの感覚がそのまま効きます。

だから、いまのうちに、shape を追う癖をしっかりつけておきましょう。

### 3.6　本章のまとめ

- 層に並んだ複数のニューロンの重みは、1つの重み行列にまとまる。1層の順伝播は `W・x + b`。
- PyTorch の `nn.Linear` の `weight` は `[出力, 入力]` の順、`bias` は `[出力]`。これは規約。
- 順伝播とは、入力を層に通して、shape を変えながら前へ計算していくこと。それだけ。
- バッチを使うと入力は `[batch_size, in_features]` になり、先頭のバッチ次元は層を通しても保たれる。
- 各データは独立に、同じ重みで変換される。「shape を追う」習慣は、後の巻で Attention を読むときの土台になる。
