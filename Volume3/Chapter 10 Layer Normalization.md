# 第10章　Layer Normalization

**この章でわかること**

- 層をまたぐと、値のスケールが暴れること
- 正規化の復習（第2巻の回収）
- LayerNorm とは何かを、具体的な数で確かめる
- gamma と beta の役割
- LayerNorm を実装し、残差接続と組み合わせて、論文の形に近づける

前章の残差接続と並ぶ、この巻のもう一つの仕込みが、LayerNorm です。

論文の `LayerNorm(x + Sublayer(x))` の、外側の `LayerNorm(...)` が、これです。

### 10.1　層をまたぐと値のスケールが暴れる

ニューラルネットを順伝播していくと、何が起きるでしょうか。

各層を通るたびに、テンソルの値の大きさ（スケール）が、変わっていきます。

ある層では値が大きくなり、別の層では小さくなる。

具体的なイメージで言うと、こうです。

```text
入力        : だいたい -1 〜 1 くらいの値
1層通った後 : だいたい -5 〜 5 くらいに広がった
2層通った後 : だいたい -50 〜 50 くらいに、さらに広がった
...
```

層が深くなると、このばらつきが積み重なります。

値が大きくなりすぎると、勾配が暴れます。

値が小さくなりすぎると、勾配が消えます。

どちらも、学習を不安定にします。

前章の残差接続は、「勾配の通り道」を確保することで、この問題に対処しました。

LayerNorm は、別の角度から対処します。

「各層に入る値のスケールを、整える」のです。

スケールがいつも同じくらいに保たれていれば、値が暴れることも、消えることも、起きにくくなります。

### 10.2　正規化の復習（第2巻の回収）

第2巻13章で、平均・分散・標準偏差と、正規化を学びました。

正規化とは、データから平均を引き、標準偏差で割って、「平均0・ばらつき1」にそろえる操作でした。

```text
正規化後 = (値 - 平均) / 標準偏差
```

具体的な数で、思い出しましょう。

たとえば、`[10, 20, 30, 40]` という4つの値があるとします。

平均は `(10+20+30+40)/4 = 25` です。

各値から平均を引くと、`[-15, -5, 5, 15]` です。

これを標準偏差（このデータでは約11.2）で割ると、だいたい `[-1.34, -0.45, 0.45, 1.34]` になります。

もとは10〜40だった値が、-1.34〜1.34 の範囲に整いました。

これが正規化です。

「大きさはバラバラだったものを、だいたい同じスケールにそろえる」操作です。

LayerNorm は、この正規化を「1つのトークン（1本のベクトル）の中で」行うものです。

### 10.3　LayerNorm とは何か（数で確かめる）

**Layer Normalization**（LayerNorm）は、1つのデータ（ベクトル）の **特徴量の次元方向** で、平均と標準偏差を取り、正規化します。

言葉だと分かりにくいので、具体例で見ましょう。

あるトークンの表現ベクトルが、`[10.0, 20.0, 30.0, 40.0]` だったとします（長さ4）。

LayerNorm は、この4つの値について、平均と標準偏差を計算します。

```text
平均     = 25.0
標準偏差 ≈ 11.18
```

そして、正規化します。

```text
正規化 = ([10,20,30,40] - 25) / 11.18
       ≈ [-1.34, -0.45, 0.45, 1.34]
```

これが LayerNorm の基本動作です。

ここで重要なのは、「1本のベクトルの中だけで」完結していることです。

バッチの中の他のデータは、いっさい関係しません。

トークン1本ずつ、独立に整えるのです。

この「他のデータに依存せず、1本のベクトルの中だけで完結する」という性質が、系列を扱う Transformer と、とても相性がよいのです。

文の長さがバラバラでも、他の文が何であっても、各トークンを独立に整えられるからです。

これが、論文で LayerNorm が採用されている理由の一つです。

### 10.4　gamma と beta の役割

正規化して「平均0・ばらつき1」にそろえるだけだと、一つ困ったことがあります。

表現の自由度が、下がってしまう場合があるのです。

「いつも平均0・ばらつき1」に強制されると、モデルが本当に出したかった値の大きさを、表現できなくなることがあります。

そこで LayerNorm は、正規化したあとに、学習可能な2つのパラメータで、スケールと位置を調整し直します。

```text
出力 = gamma × 正規化(v) + beta
```

`gamma`（ガンマ、スケール）は、ばらつきの大きさを調整します。

`beta`（ベータ、ずらし）は、全体を上下にずらします。

この2つは、学習で決まるパラメータです。

これにより、「いったん整えるが、必要ならもとのようなスケールにも戻せる」という、柔軟さを残します。

最初は `gamma = 1`、`beta = 0`（つまり、ただ正規化するだけ）から始まり、学習を通じて、ちょうどよい値に調整されていきます。

第2巻13章で触れた gamma と beta は、これです。

### 10.5　LayerNorm を実装する

PyTorch には、`nn.LayerNorm` があります。

正規化する次元のサイズ（ここでは特徴量の次元）を渡します。

```python
import torch
import torch.nn as nn

d_model = 4
ln = nn.LayerNorm(d_model)

x = torch.tensor([[1.0, 2.0, 3.0, 4.0],
                  [10.0, 20.0, 30.0, 40.0]])   # [batch=2, d_model=4]

out = ln(x)
print(out)
print(out.mean(dim=-1))   # 各行の平均 ≈ 0
print(out.std(dim=-1))    # 各行のばらつき ≈ 1（gamma=1,beta=0 の初期値時）
```

注目してほしいのは、入力の2行です。

1行目は `[1, 2, 3, 4]`、2行目は `[10, 20, 30, 40]` で、2行目は1行目の10倍のスケールです。

ところが、LayerNorm を通すと、どちらの行も「平均0・ばらつき1」付近にそろいます。

入力のスケールの違い（10倍）が、吸収されるのです。

これが、LayerNorm の働きです。

「入ってくる値が大きかろうが小さかろうが、出ていくときは同じくらいのスケールに整える」。

中身を理解するために、手で書いてみましょう。

正規化の式そのものです。

```python
import torch

def my_layernorm(x, eps=1e-5):
    mean = x.mean(dim=-1, keepdim=True)
    var = x.var(dim=-1, unbiased=False, keepdim=True)
    return (x - mean) / torch.sqrt(var + eps)   # gamma=1, beta=0 の場合

x = torch.tensor([[1.0, 2.0, 3.0, 4.0]])
print(my_layernorm(x))
```

`mean` で平均を引き、`sqrt(var)`（標準偏差）で割る。

第2巻13章の正規化の式、そのままです。

最後に、`eps`（イプシロン）について。

これは、標準偏差が0に近いときの「ゼロ割り」を防ぐための、小さな数です。

もし全部同じ値だと、標準偏差が0になり、0で割ることになってしまいます。

それを防ぐため、ごく小さな数（`1e-5` など）を足しておくのです。

実装上の定番なので、覚えておくとよいです。

### 10.6　残差接続と LayerNorm を組み合わせる

第9章の残差接続と、この章の LayerNorm。

この2つを組み合わせると、ついに論文のブロックの骨格が書けます。

```python
import torch
import torch.nn as nn

class Block(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.fc = nn.Linear(dim, dim)
        self.act = nn.ReLU()
        self.norm = nn.LayerNorm(dim)

    def forward(self, x):
        f = self.act(self.fc(x))   # f = Sublayer(x) にあたる
        return self.norm(x + f)    # LayerNorm(x + Sublayer(x))

block = Block(4)
x = torch.randn(2, 4)
print(block(x).shape)              # torch.Size([2, 4])
```

`forward` の最後の行を、よく見てください。

```text
self.norm(x + f)
```

これは、まさに `LayerNorm(x + Sublayer(x))` の形です。

`x + f` が残差接続（第9章）、`self.norm(...)` が LayerNorm（本章）。

ここでの `Sublayer`（つまり `f`）は、ただの線形＋ReLU です。

しかし、第5巻でこれを Attention や FFN に差し替えれば、Transformer のブロックそのものになります。

骨格は、もうできているのです。

### 10.7　論文の `LayerNorm(x + Sublayer(x))` を読み解く準備

第1章で「謎にしない」と約束した、論文の一行に戻りましょう。

```text
LayerNorm(x + Sublayer(x))
```

いまや、この式は、分解して読めます。

```text
x                      … 入力（前の層の出力）
Sublayer(x)            … Attention や FFN（中身は第5巻で作る）
x + Sublayer(x)        … 残差接続（第9章）。勾配のバイパス
LayerNorm(...)         … 値のスケールを整える（本章）
```

中身（Sublayer）が何であれ、それを「残差接続で包み、LayerNorm で整える」というブロックの骨格は、この巻で完成しました。

あとは、第5巻で `Sublayer` の中身（Attention）を作り、第7巻で積み上げて動かすだけです。

最後に、一つ補足です。

論文では `LayerNorm(x + Sublayer(x))`、つまり「残差を足した後に LayerNorm」という順番です（これを Post-LN と呼びます）。

一方、現代の実装では `x + Sublayer(LayerNorm(x))`、つまり「LayerNorm を先にかけてから Sublayer」という順番（Pre-LN）も、よく使われます。

順番の違いと、それぞれの安定性については、第5巻で部品を組むときに、改めて触れます。

いまは、「残差接続と LayerNorm で、サブlayer を包む」という骨格を、つかんでおけば十分です。

### 10.8　本章のまとめ

- 層をまたぐと値のスケールが暴れ、学習が不安定になる。LayerNorm はこれを整える。
- LayerNorm は1本のベクトルの特徴量次元方向で「平均0・ばらつき1」に正規化し、`gamma`・`beta` で調整し直す。
- 例：`[10,20,30,40]` は平均25・標準偏差11.18で割って `[-1.34,...,1.34]` に。1本の中だけで完結する。
- バッチの他データに依存せず1本ずつ完結するため、系列を扱う Transformer と相性がよい。
- 残差接続と組み合わせると `LayerNorm(x + Sublayer(x))` の骨格になる。`Sublayer` の中身は第5巻。Post-LN と Pre-LN の違いも第5巻で。
