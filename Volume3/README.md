# 第3巻　ニューラルネットの基礎 — *Layers Are All You Need*

教科書シリーズ「**T Is All You Need**」（全8巻）の第3巻です。
第1巻12章で植えた「ニューラルネットワークの直感」を、この巻で **手が動く実体** に変えます。

## この巻の位置づけ

- **入口（前提）**: 第1巻・第2巻。数学を既習なら第2巻を飛ばしてここから始められます。
- **出口（読了後にできること）**: 小さな MLP を自分で書いて、最後まで学習させ切れる。残差接続と LayerNorm を、なぜ必要かまで含めて実装できる。
- **立ち位置**: この巻から **手が動く（実装と厳密）**。第1巻が直感、この巻が実体です。
- **仕込み**: 残差接続と LayerNorm をここで仕込み、第6巻で読む論文の `LayerNorm(x + Sublayer(x))` を謎にしない。

## この巻でやらないこと（＝次の巻の仕事）

- 「ニューロンとは何か」をゼロから説明する（第1巻12章で済んでいる）
- 言語・トークン・embedding を本格的に扱う → **第4巻**
- Self-Attention・Q/K/V・Multi-Head など Transformer の部品を作る → **第5巻**
- 自前の autograd フレームワークを作る（別の山。この巻の目的から外れる）
- 部品を統合して動く言語モデルにする → **第7巻**

## 読み方

1. [第1章 この巻の地図](Chapter%201%20Map%20of%20This%20Volume.md) から順番に読む
2. 各章のコードを手元で動かし、shape と値を `print` で確かめる
3. [第8章 ミニ MLP を最後まで学習させ切る](Chapter%208%20Training%20a%20Mini%20MLP%20End%20to%20End.md) で、XOR を解くモデルを学習させ切る
4. [第9章 残差接続](Chapter%209%20Residual%20Connections.md) と [第10章 Layer Normalization](Chapter%2010%20Layer%20Normalization.md) で、論文のブロックの骨格を実装する

## 構成（全12章）

- 第1章: この巻の地図（やらないことの固定）
- 第2章〜第4章: 線形モデルから多層へ、順伝播、活性化関数
- 第5章〜第8章: 出力層と損失、逆伝播、学習ループ、ミニ MLP を学習させ切る
- 第9章〜第11章: 残差接続、LayerNorm、学習を安定させる小技
- 第12章: まとめ（部品表と第4巻への橋）

## 実行環境

```bash
python3 -c "import torch; print(torch.__version__)"
```

この巻のコードはすべて小さく、CPU だけで一瞬で動きます。目的は性能ではなく、「順伝播・損失・逆伝播・更新の一周を自分のコードで通す」ことです。
