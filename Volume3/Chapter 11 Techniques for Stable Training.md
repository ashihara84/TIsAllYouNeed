**この章でわかること**

この章は、ここまでの MLP を「ちゃんと学習させ切る」ために知っておくと役立つ、実務寄りの小技をまとめます。

ここで大切なのは、網羅ではありません。

「学習を安定させる小技」は、突き詰めればきりがなく、たくさんあります。

しかし、この巻のスコープに沿って、後の巻（特に第7巻の学習）で実際に効くものに、絞ります。

「これも、あれも」と並べるのではなく、効くものを、確かに押さえる。

これも、この巻の進め方です。

### 11.1　重みの初期化

ニューラルネットの重みは、学習を始める前に、ある値で初期化されます。

この初期値が悪いと、何が起きるでしょうか。

最初から勾配が暴れたり、消えたりして、学習が立ち上がりません。

スタート地点が悪いと、そもそも下り始められない、というイメージです。

幸い、PyTorch の `nn.Linear` などは、最初から「だいたい良い」初期化を使ってくれます。

具体的には、入出力の次元に応じて、適切なばらつきになるように、ランダムな値を入れてくれます。

だから、多くの場合、自分で初期化を書く必要はありません。

ただ、知っておくとよい大切なことが、一つあります。

**「全部0で初期化してはいけない」** ということです。

なぜでしょうか。

もし全パラメータが同じ値（たとえば全部0）だと、すべてのニューロンが、まったく同じ勾配を受け取ります。

すると、すべてのニューロンが、まったく同じように動いてしまいます。

8個のニューロンを置いても、全部が同じ動きをするなら、1個と変わりません。

層を広げた意味が、なくなってしまうのです。

これを防ぐために、重みはランダムに初期化します。

少しずつ違う値から始めることで、各ニューロンが、別々の役割を学べるようになります。

### 11.2　学習率のウォームアップと減衰の直感

学習率は、固定でなく、学習の進み具合に応じて変えると、安定することがあります。

2つの代表的な工夫を紹介します。

**ウォームアップ**（warmup）。

最初の数百〜数千ステップだけ、学習率を0から目標値まで、徐々に上げていきます。

なぜでしょうか。

学習の初期は、モデルがまだランダムで、不安定です。

そんなときに、いきなり大きく動かすと、おかしな方向へ飛んでいってしまう危険があります。

だから、最初はそっと小さく動かし、だんだん本来の大きさに上げていく。

これがウォームアップです。

「いきなり全力で走らず、まず準備運動をする」というイメージです。

**減衰**（decay）。

学習が進んだら、学習率を、徐々に下げていきます。

最初は大きく動いて、大まかに正解へ近づく。

後半は小さく動いて、細かく調整する。

「最初は大胆に、最後は慎重に」というイメージです。

第6巻で論文の学習設定を読むと、まさにこのウォームアップ付きの学習率スケジュールが出てきます。

いまは「学習率は途中で変えてよいし、変えると安定する」という直感を、持っておけば十分です。

### 11.3　過学習への基本対処（Dropout を実装で）

第1巻7章で、過学習を学びました。

過学習とは、「訓練データには強いが、本番（未知のデータ）には弱い」状態でした。

その対処の代表が、**Dropout**（ドロップアウト）です。

Dropout は、学習中に、各ニューロンの出力を、ランダムに一定割合だけ0にします。

たとえば「50%の確率で0にする」なら、学習のたびに、半分くらいのニューロンが、ランダムに休む、というイメージです。

なぜ、こんなことをすると過学習が抑えられるのでしょうか。

ニューロンがランダムに休むと、モデルは「特定のニューロンに頼りきる」ことができなくなります。

「あのニューロンが、たまたま訓練データのこの特徴を覚えている」という、危うい頼り方ができなくなるのです。

その結果、より頑健な（どのニューロンが休んでも大丈夫な）表現を学ぶようになります。

実装で確かめましょう。

```python
import torch
import torch.nn as nn

drop = nn.Dropout(p=0.5)   # 50% を0にする

x = torch.ones(2, 6)

drop.train()               # 学習モード：ランダムに0にする
print(drop(x))

drop.eval()                # 推論モード：何もしない（そのまま通す）
print(drop(x))
```

ここで、とても重要な点があります。

Dropout は、**学習中だけ** 働きます。

推論時（実際に使うとき）には、何もしません。

学習中は、わざとニューロンを休ませて、頑健さを鍛える。

本番では、全ニューロンを使って、ベストを尽くす。

この切り替えは、`model.train()` と `model.eval()` で行います。

`train()` にすると Dropout が有効になり、`eval()` にすると無効になります。

第8章で `no_grad` とあわせて `eval()` を使ったのを、思い出してください。

なお、Transformer にも Dropout は使われています。

第6巻で、論文の正則化として、Dropout が出てきます。

### 11.4　勾配が爆発・消失するとき

深いネットワークでは、勾配が極端に大きくなる（爆発）か、極端に小さくなる（消失）ことがあります（第9章でも触れました）。

それぞれの対処を、整理しておきます。

**勾配消失への対処。**

- ReLU を使う（第4章）。正の領域で傾き1なので、勾配が流れやすい。
- 残差接続を使う（第9章）。「+1」のバイパスで、勾配が流れる。
- LayerNorm を使う（第10章）。スケールを整え、暴れを抑える。

この巻で仕込んだものが、まさに勾配消失への対処になっているのです。

**勾配爆発への対処。**

代表が、**勾配クリッピング**（gradient clipping）です。

勾配の大きさが、ある上限を超えたら、上限で頭打ちにする方法です。

「勾配が大きくなりすぎたら、強制的に制限する」というイメージです。

```python
import torch.nn as nn
# 学習ループの backward と step の間に挟む
# loss.backward()
nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
# optimizer.step()
```

`backward()`（勾配を計算）と `optimizer.step()`（更新）の間に、この一行を挟みます。

すると、勾配の大きさが `max_norm`（ここでは1.0）を超えないように、抑えられます。

勾配クリッピングは、Transformer の学習でも、安定化のためによく使われます。

### 11.5　本章のまとめ

- 重みはランダムに初期化する（全0は不可。全ニューロンが同じ動きをしてしまう）。PyTorch の既定で多くは十分。
- 学習率は固定でなくてよい。ウォームアップ（最初に上げる）と減衰（後で下げる）で安定する。論文にも登場する。
- Dropout は学習中だけニューロンの出力をランダムに0にして、過学習を抑える。`train()`/`eval()` で切り替わる。
- 勾配消失には ReLU・残差接続・LayerNorm（この巻で仕込んだもの）、勾配爆発には勾配クリッピングが効く。
- 網羅でなく、後の巻で効くものに絞った。いずれも第6巻・第7巻で再登場する。
