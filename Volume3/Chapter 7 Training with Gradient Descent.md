# 第7章　勾配降下で学習させる

**この章でわかること**

- optimizer（最適化器）の役割
- 学習ループの骨格：forward → loss → backward → step
- 学習率とエポックの、実際の意味
- SGD から Adam / AdamW への切り替え
- 学習が進んでいるかを、損失で確認する

### 7.1　optimizer を用意する（SGD）

前章で、勾配が求まりました。

各パラメータについて、「損失を下げるには、どちらへ動かせばよいか」が分かった、ということです。

あとは、その情報を使って、パラメータを更新するだけです。

更新の式は、前章で見たとおりでした。

```text
新しい重み = 今の重み - 学習率 × 勾配
```

この更新を担当するのが、**optimizer**（最適化器）です。

「最適化」とは、損失を最小にする、という意味でした（第1巻5章）。

いちばん基本的な optimizer が、SGD（確率的勾配降下法）です。

第1巻5章、第2巻11章で学んだ勾配降下法、そのものです。

PyTorch で用意してみましょう。

```python
import torch
import torch.nn as nn

model = nn.Sequential(nn.Linear(3, 4), nn.ReLU(), nn.Linear(4, 2))

optimizer = torch.optim.SGD(model.parameters(), lr=0.1)
```

`model.parameters()` で、モデル内のすべてのパラメータを、optimizer に渡しています。

第3巻5章で「`nn.Module` のパラメータは自動登録される」と学びました。

そのおかげで、`model.parameters()` だけで、モデルの全パラメータをまとめて渡せます。

`lr` は学習率です。

これで optimizer は、「どのパラメータを、どの学習率で更新するか」を知った状態になりました。

### 7.2　学習ループの骨格（forward → loss → backward → step）

ニューラルネットの学習は、次の4ステップの繰り返しです。

この骨格は、これから先、どんなに複雑なモデルになっても、変わりません。

第7巻で Transformer を学習させるときも、まったく同じ形です。

だから、ここでしっかり体に覚え込ませてください。

```text
1. forward : モデルに入力を通して、出力を得る
2. loss    : 出力と正解から、損失を計算する
3. backward: 損失から、勾配を計算する（逆伝播）
4. step    : optimizer が、パラメータを更新する
```

コードにすると、こうなります。

```python
import torch
import torch.nn as nn

torch.manual_seed(0)
model = nn.Sequential(nn.Linear(3, 8), nn.ReLU(), nn.Linear(8, 2))
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

x = torch.randn(20, 3)
targets = torch.randint(0, 2, (20,))

for step in range(100):
    optimizer.zero_grad()      # 前回の勾配を消す
    logits = model(x)          # 1. forward
    loss = loss_fn(logits, targets)  # 2. loss
    loss.backward()            # 3. backward
    optimizer.step()           # 4. step

    if step % 20 == 0:
        print(f"step {step:3d}  loss {loss.item():.4f}")
```

ここで、順番がとても大切です。

`optimizer.zero_grad()` で、前回の勾配を消す。

`loss.backward()` で、今回の勾配を計算する。

`optimizer.step()` で、その勾配を使って更新する。

この順番を間違えると、正しく学習できません。

特に、`zero_grad()` を忘れると、前章で述べたとおり、勾配が溜まり続けてしまいます。

「消す → 計算する → 更新する」。

この3つを、毎ステップ、この順で繰り返す。

これが学習ループの心臓部です。

### 7.3　学習率とエポックの実際

学習ループに出てくる、2つの大切な言葉を、丁寧に確認します。

**学習率**（lr）は、1回の更新で、どれだけ動くかを決めます。

第1巻5章で学んだとおり、大きすぎても小さすぎても、うまくいきません。

大きすぎると、行き過ぎて、損失が暴れます（収束しない）。

小さすぎると、なかなか進まず、学習が遅くなります。

イメージとしては、山を下りるときの「一歩の大きさ」です。

歩幅が大きすぎると谷を飛び越えてしまい、小さすぎると永遠に下りられません。

まずは `0.1` や `0.01` あたりから試して、損失の下がり方を見ながら、調整します。

**エポック**（epoch）は、訓練データ全体を1周することです。

上のループでは、同じ `x` を100回通していますが、実際にはデータをバッチに分けます。

そして、全バッチを1周したら1エポック、と数えます（第1巻5章の「エポックとステップ」の回収です）。

たとえば、1000件のデータを、100件ずつのバッチに分けると、10バッチになります。

この10バッチを全部通すと、1エポックです。

これを何エポックも繰り返して、学習を進めます。

損失が下がっていれば、学習は進んでいます。

下がらない、または増えていくなら、何かがおかしいです。

学習率が大きすぎる、実装にバグがある、などを疑います。

### 7.4　Adam / AdamW に切り替える

SGD はシンプルですが、実務では **Adam** や、その改良版 **AdamW** が、よく使われます。

これらは、パラメータごとに、学習の進み具合に応じて、実質的な学習率を自動で調整してくれます。

イメージとしては、「よく動くパラメータは慎重に、あまり動かないパラメータは大胆に」というように、賢く歩幅を変えてくれる、という感じです。

そのため、多くの場合、SGD より速く、安定して学習します。

切り替えは、たった1行です。

```python
# SGD の代わりに AdamW を使う
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3)
```

ここで大切なことがあります。

optimizer を SGD から AdamW に変えても、**学習ループの骨格は、何も変えなくてよい** のです。

`forward → loss → backward → step` の4ステップは、そのままです。

変わるのは、optimizer を作る1行だけ。

第2巻11章で「SGD・Adam・AdamW の直感」に触れました。

Transformer の学習では、AdamW が定番です。

第7巻でも AdamW を使います。

いまは「optimizer を差し替えても、骨格は不変」という点を、押さえておけば十分です。

### 7.5　学習が進んでいるかを損失で見る

学習中は、損失の値を定期的に表示して、下がっているかを目で確認するのが基本です。

たとえば、こんなふうに表示されれば、順調です。

```text
step   0  loss 0.81
step  20  loss 0.55
step  40  loss 0.39
step  60  loss 0.30
step  80  loss 0.25
```

数字が、だんだん小さくなっています。

これは、モデルが少しずつ賢くなっている証拠です。

一方、こういう表示が出たら、何かがおかしいです。

```text
step   0  loss 0.81
step  20  loss 1.95
step  40  loss 4.20    ← どんどん増えている（学習率が大きすぎる？）
```

損失が増えていくときは、まず学習率を下げてみます。

また、こういうのも要注意です。

```text
step   0  loss 0.69
step  20  loss 0.69
step  40  loss 0.69    ← まったく動かない
```

まったく動かないときは、`zero_grad()` の入れ忘れや、softmax の二重がけ（第5章）など、実装を見直します。

このように、損失の表示は、学習がうまくいっているかを知る、いちばん簡単で大切な手がかりです。

学習ループを書いたら、必ず損失を表示する。

これを習慣にしてください。

### 7.6　本章のまとめ

- optimizer は「重み − 学習率 × 勾配」の更新を担当する。最も基本は SGD。`model.parameters()` で全パラメータを渡す。
- 学習ループの骨格は forward → loss → backward → step。`zero_grad()`（消す）→ backward（計算）→ step（更新）の順を守る。
- 学習率は「一歩の大きさ」。大きすぎると暴れ、小さすぎると遅い。エポックは訓練データ全体を1周すること。
- SGD を AdamW に差し替えても、ループの骨格は変わらない（変わるのは1行）。Transformer の学習でも AdamW が定番。
- 損失が下がっているかを表示で確認するのが、デバッグの第一歩。増える・動かないときは原因を疑う。
