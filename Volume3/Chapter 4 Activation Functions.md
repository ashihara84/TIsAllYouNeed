# 第4章　活性化関数

**この章でわかること**

- なぜ層の間に、非線形な関数が必要なのか（もう一度、別の角度から）
- ReLU の動きを、具体的な数で確かめる
- なぜ ReLU がよく使われるのか
- シグモイドと tanh の特徴と弱点
- 活性化関数を順伝播に挟むと、出力がどう変わるか

### 4.1　なぜ非線形性が要るのか

前章までで何度か触れた話を、この章の出発点として、もう一度、別の角度から確かめます。

線形変換を、何回重ねても、全体としては1つの線形変換にしかなりません。

式で書くと、こうでした。

```text
y = W2・(W1・x) = (W2・W1)・x
```

`W2・W1` は1つの行列にまとまるので、結局1段と同じです。

これでは、層を深くした意味がありません。

直線でしか境界を引けない、という限界も、そのままです。

そこで、層と層の間に、**非線形な関数** を挟みます。

これが活性化関数です。

「非線形」とは、「まっすぐではない」という意味です。

直線（比例）の関係ではない、ということです。

活性化関数を挟むと、なぜ層が意味を持つのか。

それは、`W2・W1` のように1つにまとめることが、できなくなるからです。

```text
h = 活性化(W1・x + b1)   ← ここで「まっすぐでない」操作が入る
y = W2・h + b2
```

`h` を作るときに、まっすぐでない操作が入ると、`y` の式に代入しても、もう1つの行列にまとめられません。

この「まとめられなさ」が、複雑な表現を生む力の源です。

前章で「平面を折り曲げる」というイメージを使いました。

活性化関数こそが、その「折り曲げ」を担う部品です。

### 4.2　ReLU

いま、最もよく使われる活性化関数が **ReLU**（Rectified Linear Unit、レルー）です。

名前は難しそうですが、定義はとても単純です。

```text
ReLU(z) = max(0, z)
```

入力 `z` が正なら、そのまま返す。

入力 `z` が負なら、0にする。

それだけです。

具体的な数で確かめましょう。

```text
ReLU(3.0)  = 3.0    （正なので、そのまま）
ReLU(1.5)  = 1.5    （正なので、そのまま）
ReLU(0.0)  = 0.0
ReLU(-0.5) = 0.0    （負なので、0に）
ReLU(-2.0) = 0.0    （負なので、0に）
```

グラフにすると、こんな形です。

```text
出力
 |        /
 |       /
 |      /
 |     /
-+----+--------- 入力
 |   0
   負はすべて0、正はそのまま（傾き1の直線）
```

負の側は、ぺったり0。

正の側は、傾き1の直線。

「く」の字を裏返したような形です。

PyTorch で動かしてみましょう。

```python
import torch
import torch.nn as nn

relu = nn.ReLU()

z = torch.tensor([-2.0, -0.5, 0.0, 1.5, 3.0])
print(relu(z))   # tensor([0.0, 0.0, 0.0, 1.5, 3.0])
```

入力の各要素について、負は0に、正はそのままになっているのが分かります。

これほど単純なのに、ReLU が好まれるのには、理由があります。

**1. 計算が速い。**

やることは「0と比べて、大きいほうを取る」だけです。

掛け算も割り算も、指数関数も要りません。

だから、とても速く計算できます。

**2. 勾配がそのまま流れる。**

正の領域では、傾きが1です。

傾き1ということは、逆伝播（第6章）のとき、勾配がそのままの大きさで後ろへ流れる、ということです。

これは、層を深くしたときに「勾配が消えてしまう」問題（後で出てきます）を、起きにくくします。

**3. スイッチのように働く。**

「負を0にする」ことで、各ニューロンが「反応するか、しないか」を切り替えるスイッチのように働きます。

入力によって、あるニューロンは0（オフ）、別のニューロンは正の値（オン）、というふうに、使うニューロンを選ぶような振る舞いが生まれます。

第1巻12章で「活性化関数」を直感で触れましたが、その代表格が、この ReLU です。

### 4.3　シグモイドと tanh

ReLU が主流になる前は、シグモイドや tanh がよく使われていました。

いまでも、特定の場面で登場するので、知っておきましょう。

**シグモイド**（sigmoid）は、どんな数でも、0〜1 の範囲に押し込めます。

```text
sigmoid(z) = 1 / (1 + exp(-z))
```

具体的な値を見てみましょう。

```text
sigmoid(-10) ≈ 0.00004   （大きな負 → ほぼ0）
sigmoid(-2)  ≈ 0.12
sigmoid(0)   = 0.5        （0 → ちょうど真ん中）
sigmoid(2)   ≈ 0.88
sigmoid(10)  ≈ 0.99995    （大きな正 → ほぼ1）
```

出力が必ず 0〜1 に収まるので、「確率らしきもの」として解釈しやすいです。

だから、二値分類の出力などで使われます（第1巻8章のロジスティック回帰を思い出してください）。

**tanh**（ハイパボリックタンジェント）は、どんな数でも、-1〜1 の範囲に押し込めます。

形はシグモイドに似ていますが、出力が0を中心に対称になります。

```text
tanh(-2) ≈ -0.96
tanh(0)  = 0.0
tanh(2)  ≈ 0.96
```

PyTorch で両方を確かめましょう。

```python
import torch

z = torch.tensor([-2.0, 0.0, 2.0])
print(torch.sigmoid(z))  # 0〜1 に収まる
print(torch.tanh(z))     # -1〜1 に収まる
```

これらには、共通の弱点があります。

入力が大きく（または小さく）なると、出力がほぼ平らになり、傾きがほぼ0になることです。

たとえば、`sigmoid(10)` も `sigmoid(20)` も、ほぼ1で、ほとんど変わりません。

ということは、その付近では傾き（変化の割合）がほぼ0です。

傾きが0だと、逆伝播のとき、勾配がほとんど流れません。

これを **勾配消失** と呼びます。

層を深くすると、この問題が効いてきます。

何段も「傾きほぼ0」を通ると、勾配がどんどん小さくなり、入力側の層まで届かなくなるのです。

ReLU が広まったのは、この弱点が小さいからでした。

ReLU は、正の領域では傾き1なので、勾配がそのまま流れます。

### 4.4　活性化関数の選び方の直感

たくさんあると、どれを使えばいいか迷います。

迷ったときの、現代の標準的な出発点は、こうです。

**隠れ層には、まず ReLU を使う。**

ReLU で試して、問題が出たら、その派生（Leaky ReLU、GELU など）を検討します。

**出力層は、問題に合わせる。**

- 二値分類なら、シグモイド（0〜1の確率に）。
- 多クラス分類なら、softmax（次章で扱います）。
- 回帰なら、活性化なし（そのまま実数を出す）。

出力層は、「何を出したいか」で決まります。

確率を出したいなら、確率に変える関数を使う、というわけです。

なお、Transformer の Feed-Forward Network では、ReLU やその親戚である GELU がよく使われます。

第5巻でこの部品を作るとき、ここで得た直感が、そのまま効きます。

「FFN の中に活性化が入っているのは、ここで学んだ非線形性のためだ」と分かるはずです。

### 4.5　活性化関数を順伝播に挟む（実装）

活性化を挟むと、出力が実際にどう変わるか。

活性化の「あり」と「なし」で、出力を比べてみましょう。

```python
import torch
import torch.nn as nn

torch.manual_seed(0)

l1 = nn.Linear(2, 4)
l2 = nn.Linear(4, 1)
relu = nn.ReLU()

x = torch.tensor([1.0, -1.0])

# 活性化なし（線形を2回）
y_linear = l2(l1(x))

# 活性化あり（間に ReLU）
y_relu = l2(relu(l1(x)))

print("活性化なし:", y_linear.item())
print("活性化あり:", y_relu.item())
```

途中の隠れ表現に ReLU を通すと、負の成分が0に切り落とされます。

その結果、そのあとの出力が、活性化なしのときとは違う値になります。

何が起きているかを、もう少し丁寧に見ましょう。

`l1(x)` の結果（隠れ表現）に、たとえば `[0.7, -0.3, 1.2, -0.8]` のような値が出たとします。

ReLU を通すと、負の成分が0になり、`[0.7, 0.0, 1.2, 0.0]` になります。

この「一部を0に切り落とす」操作が、活性化なしでは決して起きません。

活性化なしだと、負の値もそのまま次の層へ流れます。

この「途中で非線形に折り曲げる（一部を0にする）」操作の積み重ねが、ニューラルネットの表現力を生み出しているのです。

### 4.6　本章のまとめ

- 線形変換だけを重ねても線形のまま。間に **非線形な活性化関数** を挟むことで、表現力が生まれる。
- ReLU は `max(0, z)`。負を0に、正はそのまま。単純・高速で、正の領域では勾配がそのまま流れるため、いま最もよく使われる。
- シグモイド（0〜1）と tanh（-1〜1）は範囲を押し込めるが、両端で傾きがほぼ0になり、勾配消失が起きやすい。
- 隠れ層はまず ReLU、出力層は問題に合わせて選ぶ。Transformer の FFN でも ReLU/GELU が使われる。
- 活性化は「途中で一部を0に折り曲げる」操作。これの積み重ねが表現力を生む。
