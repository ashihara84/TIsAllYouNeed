# 用語集（第3巻）

この巻で出てくる基本語をまとめます。第1巻・第2巻で既に出た語は、ここでは「実装での意味」に寄せて説明します。

- **ニューロン**: 入力ベクトルとの内積にバイアスを足して1つの数を返す、最小の計算単位。`y = w・x + b`。
- **MLP（多層パーセプトロン）**: 線形変換と活性化関数を順につないだニューラルネットワーク。この巻で最初に自分で書くモデル。
- **隠れ層**: 入力層と出力層の間の層。入力を、次の判断に使いやすい表現へ変換する。
- **重み行列 / バイアス**: 1層の線形変換 `W・x + b` のパラメータ。`nn.Linear` の `weight`（`[出力, 入力]`）と `bias`（`[出力]`）。
- **順伝播（forward propagation）**: 入力を層に通して、出力（や損失）まで前向きに計算すること。
- **バッチ**: 複数のデータをまとめて流す単位。入力は `[batch_size, in_features]`。
- **活性化関数**: 層の間に挟む非線形な関数。ReLU、シグモイド、tanh など。これがないと層を重ねても線形のまま。
- **ReLU**: `max(0, z)`。負を0にする活性化関数。単純・高速で勾配が流れやすく、現代の標準。
- **ロジット（logits）**: 出力層が出す生のスコア。softmax を通す前の値。
- **softmax**: ロジットを合計1の確率分布に変える関数（第2巻7章）。
- **交差エントロピー（cross entropy）**: 分類の損失 `-log(正解の確率)`。`nn.CrossEntropyLoss` は内部で softmax を行う。
- **勾配（gradient）**: 各パラメータについての損失の傾き。逆向きに動かすと損失が下がる。
- **逆伝播（backpropagation）**: 連鎖律で、出力側から入力側へ勾配を伝える計算。`loss.backward()` が自動で行う。
- **autograd**: PyTorch の自動微分。順伝播を記録し、`backward()` で勾配を自動計算する仕組み。
- **optimizer**: パラメータ更新を担当する。SGD、Adam、AdamW など。`optimizer.step()` で更新。
- **学習率（learning rate, lr）**: 1回の更新でどれだけ動くか。大きすぎると暴れ、小さすぎると遅い。
- **エポック**: 訓練データ全体を1周すること。
- **`nn.Module`**: 自分のモデルや部品を定義する基底クラス。`__init__` で部品、`forward` で流れを書く。
- **残差接続（residual connection）**: `出力 = x + f(x)`。勾配の「バイパス」を作り、深いネットの学習を助ける。論文の `x + Sublayer(x)`。
- **LayerNorm（Layer Normalization）**: 1本のベクトルの特徴量次元で平均0・ばらつき1に正規化し、`gamma`・`beta` で調整する。論文の `LayerNorm(...)`。
- **Dropout**: 学習中にニューロンの出力をランダムに0にして過学習を抑える。推論時は働かない。
- **勾配クリッピング**: 勾配が大きすぎるときに上限で頭打ちにし、勾配爆発を防ぐ。
- **`LayerNorm(x + Sublayer(x))`**: Transformer のブロックの骨格。残差接続（第9章）と LayerNorm（第10章）の組み合わせ。中身の `Sublayer` は第5巻で作る。
